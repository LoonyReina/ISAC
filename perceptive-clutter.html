接收处理 / 先保留复数，再学习背景

递归去背景：
为什么慢目标也会变弱？

把墙的回波记成背景，再减掉它。可一个慢慢移动的目标，会不会也被记进去？

本页只处理同一格复信道随时间的变化。先看懂一支箭头，再手算两步；原文、噪声和研究边界放在下方展开阅读。

01 / 先看接收机拿到了什么

一格读数里，墙和目标叠在一起

固定同一用户、同一子载波、同一对收发天线。每隔 2 ms 取一次已经去除已知通信调制的复信道读数，记为 x。它有实部 I 和虚部 Q，像一支有长度、有方向的箭头。

接收机只能看到总和 x。它并不知道哪一部分来自墙、哪一部分来自目标。这里先不求距离和方向，只问：能不能用过去的读数学习稳定背景 b，再留下变化的部分 r？

静态不等于无用；是否移除要由任务决定。这里观察背景相减的作用，不预先把所有静止物体都当成干扰。

x = b + r

这是复数相加，不是功率相加，也不是房间里的位置关系。幅度的单位是归一化信道系数；幅度平方才是归一化功率，不能读成瓦特或 dBm。

先猜一下：目标相位每次只转过一点点，会不会看起来也像“稳定背景”？

02 / 用两步算清楚规则

旧背景留一点，新读数放一点

α（读作 alpha）控制保留多少旧背景。例如 α=0.95，就是旧背景占 95%，新读数占 5%。从 b₀=0 开始，每来一个新读数，先更新背景，再做复数相减：

bp = α bp−1 + (1−α) xp rp = xp − bp

p 是第几次观测。相减时，I 减 I，Q 减 Q。背景与剩余都可以带正负号；不能先平方，再把两份功率相减。

第 1 步

先用一个无噪声小例子：α=0.5，x₁=1+j，初始 b₀=0。

b₁ = 0.5×0 + 0.5×(1+j)
= 0.5+0.5j

r₁ = (1+j) − (0.5+0.5j)
= 0.5+0.5j

第 2 步

下一个输入 x₂=2−j。先保留刚才背景的一半，再加入新读数的一半。

b₂ = 0.5×(0.5+0.5j) + 0.5×(2−j)
= 1.25−0.25j

r₂ = (2−j) − (1.25−0.25j)
= 0.75−0.75j

第二步里，第一个读数的权重已经从 0.5 降到 0.25。越旧的读数，留下的权重越小。α 越大，背景记得越久，但改变得越慢。

04 / 保持预算，让目标慢下来

它仍在动，却越来越像背景

这里的 fD 是目标在复平面里每秒转多少圈，单位 Hz。默认 2 Hz；改成 0.5 Hz 后，每次观测间的转角更小。输入目标的幅度没变，但背景更容易跟上它。

较大 α 能让慢目标的稳态通过量增加，同时让静态背景建立更慢。稳态曲线与这 512 次的能量比回答不同问题，不能互相替代，更不是检测概率或估计准确率。

α=0：默认时序把当前输入全部学入背景，剩余为零。目标和噪声也一起归零，不代表完美感知。

α=1：背景永远停在初值 0，输出就是输入，完全没有学背景。

fD=0：目标也变成常量。只看这一格复数，无法把静态墙与静止目标分开。

再往下一层：停止、离开、相减时序与相关噪声

背景也会记住过去的目标

这些设置不增加采样数或隐藏预热。停止模式让目标在 p=256 后保持原有相位；离开模式从 p=257 起把目标分量置零。观察最后一段：残余的尾迹可能来自旧背景，并不证明又出现了一个目标。

两种模式都按相同规则更新背景。“旧背景”模式显示 up=xp−bp−1；默认模式显示 rp=xp−bp。它们满足 rp=αup。α>0 时只是输出尺度不同，噪声也一起缩放；用同一个绝对检测门限比较会混入尺度差异。

图和读数跟随当前时序。默认数学规则“先更新再相减”也可等价实现为 r=α(x−旧背景)，以减轻浮点消减误差。α=0 时 r=0，但旧背景输出 u 不必为零；α=1 时两种输出都等于 x。

背景估计的噪声小，不等于输出没有噪声

输入噪声的归一化功率是 σ²=E|n|²，两路 I/Q 的方差各为 σ²/2。递归会让背景变平滑；但当前噪声也参与当前背景，所以相减时不能把它们当作互不相关。

同一种子产生相同的标准化噪声；改 α、频率、时序或视图不会重新抽样。改 σ² 只缩放同一份噪声。

等待输入、背景估计和当前输出的解析噪声方差。

等待相邻时刻噪声协方差；非零协方差意味着输出在慢时间上不再是白噪声。

展开有限时刻的方差与协方差

令 βp 是背景估计里的噪声，ηp 是默认输出 r 里的噪声。输入 np 独立且服从 proper 复高斯分布，初值 b₀=0。下面为本课独立推导：

Vb(p) = E|βp|² = σ² (1−α)/(1+α) · (1−α2p)E[npβp*] = (1−α)σ²Kpp = E|ηp|² = σ² [2α²/(1+α) − (1−α)/(1+α) · α2p]Kpq = −σ² (1−α)/(1+α) · [α|p−q|+1 + αp+q]，p≠q

K 的对角线是方差，非对角线是时刻之间的协方差。旧背景输出的方差为 σ²+Vb(p−1)；α>0 时，它的完整协方差为 K/α²。零噪声时方差与协方差为零，相关系数不定义。

若把背景冻结后用于将来独立的新观测，其噪声方差是 σ²+Vb(p)，又是另一种条件。多个新观测共用同一冻结背景，也会共享背景误差。本页只模拟更新时刻，不模拟更新间插入的观测。

不能把这条相关输出直接套进要求独立训练样本的 CA-CFAR 公式。本页没有门限、虚警率或检出率曲线；一次固定种子记录也不是独立 Monte Carlo 试验。

整圈采样检查：每 2 ms 采样一次，即 500 Hz。一个 500 Hz 的复正弦每次正好转一整圈，采样结果与 0 Hz 相同，也会被当作静态。这是采样别名；主控限制为 −100 至 100 Hz，不表示现实运动不会混叠。复慢时间通常约定不模糊区间为 [−250,250) Hz。

直接展开递归，得到有限时刻复响应

对 sp=A exp[j(φ+ωp)]，ω=2πfDTh，从 b₀=0 得：

bps = A exp[j(φ+ωp)] (1−α) [1−(α exp(−jω))p] / [1−α exp(−jω)]

对 0≤α<1，启动项消失后的背景响应 Hb=(1−α)/(1−α exp(−jω))；默认输出响应 G=1−Hb。目标功率比要算 |1−Hb|²，不能写成 1−|Hb|²。α=1 由原始递归单独处理，避免在零频率处套出 0/0。

模型、资源账本与研究下一问

生成器知道什么，接收机又知道什么？

xp = C + A exp[j(φ+2πfDpTh)] + npp=1,…,512；Th=0.002 s；b₀=0

默认真值 C=4 exp(j0.3)、A=1、φ=1.1 rad、fD=2 Hz；输入噪声独立，np∼CN(0,0.04)。C、A、φ、fD 只供生成和评估，接收滤波器不知道这些真值，只使用复数输入 x、α 和初始状态。真值分量的残余与能量比是把各分量单独送入同一线性滤波器得到的教学诊断。

固定时延和阵列相位被吸收到复增益里，仅保留随慢时间变化的载波相位。这是固定复系数的局部近似，未指定可验证的距离 / 角度分辨单元，不能据此保证长距离运动始终没有单元迁移。持续正弦贯穿本次记录是教学假设。

哪些资源一样，哪些没有建模？

  • 固定 512 个慢时间观测，间隔 2 ms；这里的 512 不是原论文的 512 个子载波。2 ms 也不是 OFDM 符号时长、快时间采样间隔或 5G slot。
  • 采样率 500 Hz；第一次观测为 2 ms，最后一次为 1.024 s，首末跨度 1.022 s。常用 DFT 记账时长 P Th=1.024 s，格距 1/(P Th)=0.9765625 Hz；本页不画频谱。
  • 所有 α 与相减时序对照使用同一记录、同一噪声、同一初值。前 64 次 / 全部 / 最后 128 次只是视图，不额外加入训练历史，不归一化冷启动权重。
  • 新样本权重为 1−α，旧样本逐次衰减；到第 p 次，权重和只有 1−αp。对常量 C，默认静态残余为 Cαp。
  • 对 0<α<1，衰减时间 τ=−Th/ln α；稳态权重平均年龄 Thα/(1−α)，两者定义不同。默认 α=0.95 时分别约 38.99 ms 与 38 ms。
  • 默认目标 / 噪声功率比为 1/0.04=25（约 13.98 dB），静态 / 目标功率比为 16（约 12.04 dB）。不能把有交叉项的总输入功率当成目标 SNR。
  • 各模式都是数字重处理，不额外增加发射能量。但未建模带宽、阵列孔径、通信符号开销、吞吐量、RCS、RF 功耗、硬件饱和或链路预算。

“衰减”为什么不自动等于 Fisher 信息损失？

对有限记录和已知初值，默认相减可写作 r=Lx。α>0 时，下三角矩阵 L 的对角为 α，所以可逆。若完整保留复数记录，后续同时使用正确变换后的均值和完整噪声协方差，不能仅凭目标幅度变小就宣布 Fisher 信息或最优估计性能必然下降。

α=0、丢弃启动或低频、只保存功率、忽略相关噪声、量化与有限精度，需要另外分析。本页不实现估计器或检测器，不报告 RMSE、CRB、检出率、虚警率或性能排名。

纯复正弦的模方是常量；先取功率会丢掉本模型里用来表达 Doppler 的相位。这里也没有把 Doppler 统一换成速度：一般双站低速窄带关系为 fD=−(dL/dt)/λ，只有另加单站径向约定时才出现双程因子 2。
