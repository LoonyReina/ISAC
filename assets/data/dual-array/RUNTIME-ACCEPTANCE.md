## Findings and verified repairs

1. **Direct-core extreme-scale false regular CRB.** The initial frozen kernel could return `regular` with NaN CRB/RCRB, and a nonfinite steering phase could become a misleading all-null estimate. Reproductions are preserved in attempt-02. The repaired kernel explicitly bounds supported floating-point energies, rejects nonfinite phases/intermediates, uses stable scaled real information and normalized 2x2 inversion, and checks its resulting bounds. Extreme gain can now produce a correct finite bound when representable; unsupported cases fail explicitly
2. **Fixed-floor semantic acceptance of erased small scientific values.** The initial importer accepted an all-zero low-gain FIM position block and whole erased tiny gains/scores. It also accepted saved zero Y while its y_sha256 named nonzero bytes. The repaired importer verifies fingerprints directly against stored actual X/Y before replay and uses homogeneous physical scales, with parameter-local diagonal scales for FIM/CRB entries. Only dimensionless diagnostics retain a unit-sized absolute tolerance. The exact original counterexamples and isolated-field regressions now reject
3. **Signed-zero serialization.** The owner identified that strengthened byte binding exposed native JSON.stringify's conversion of -0 to +0. The reviewer independently reproduced failure in four paths. Final canonical/export serialization preserves -0 and its byte budget; all four round trips pass

Old attempts and failing receipts remain unchanged for traceability. No reviewer edits were made in the producer directory. Final records-only revision 3 leaves the independently replayed numerical kernel unchanged; the final complete runtime's fresh numerical checks were repeated after that serialization revision.

## Scientific and execution boundaries that remain

- This is the bounded downlink Algorithm 1 model with known actual finite X, one target and white proper-complex noise, plus a same-Y supplied-grid joint profile comparator. Unknown beta is refitted at every candidate. Neither covariance substitution nor generating-truth estimation is accepted
- Rank one removes regular unknown-gain range information. Higher rank does not prove global identifiability. The documented exact full Fresnel alias remains indistinguishable for arbitrary X. Noise-only numerical output is not target detection
- Source-style SNR and received target SNR are distinct. Mismatched raw observations have unverified physical origin and do not inherit a valid matched-model CRB. Stored precision-grid locking is not continuous accuracy, super-efficiency or a CRB victory
- Stored historical summary import verifies exact accepted bytes and explicitly does not recompute the offline study. Partial histories and retyped summaries do not inherit that acceptance
- Headless Node workers establish actual computation/termination behavior only. No browser was opened, no UI was reviewed, no browser/device timing was certified, and no repository/remote/deployment action was taken
- Original Fig.4/HB/FD optimized curves remain source-setting blocked. No communication optimization, uplink, continuous global ML, hardware or whole-paper claim is accepted

## Reproduce

Use existing Node and Python/NumPy/SciPy, with BLAS thread counts set to one. No installation or network is required. `run_numeric_targets.mjs` accepts a source-directory path and output JSON path; add `--historical` for the 87-record batch. Run `independent_oracle.py` on that output. The records, worker, scientific-contract, signed-zero and boundary scripts accept source-directory and receipt-output paths. `generation_oracle.py` checks the scientific-contract output. `summary_metrics.py` produces independently normalized numerical metrics.

The review occupies less than 10 MB and does not duplicate the complete study archive. `AUDIT-MANIFEST.json` binds the independent scripts, retained attempts, receipts and verdict.
