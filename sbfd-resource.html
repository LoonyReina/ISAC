研究案例 04 / 从理想孔径到硬件资源

分的是带宽，
测速看的是时间

几个发射机共享一个频带，为什么还可能保持相近的测速误差？先把频谱、观察时间和实验对照的账算清。

子带全双工 SBFD频率孔径 × 时间孔径原型证据 × 独立模型

01 / 先看任务，再看缩写

三个节点，不一定要三份完整频带

先修：OFDM 的频率与慢时间、导频与距离歧义。接着时钟案例，检查原型能支持多大的结论。

主读：arXiv:2602.00054v1 的 SBFD ISAC 原型研究（版本记录：2026-01-19 提交的 v1，核对于 2026-10-10）。下面沿“问题 → 对照 → 瓶颈 → 改动 → 证据 → 边界 → 复现”读论文，而不是复画实测曲线。

  1. 问题：多发射机持续感知时，怎样同时留出通信资源，又不让每个节点独占完整信道？先问共存是否可行，再问性能最优。
  2. 基线：§II–V 比较共享频带内分子带、三个分离完整频带、完全同频重叠。多频带中心为 6.74/6.80/6.86 GHz，合计 60 MHz；SBFD 共用 20 MHz。完全重叠是干扰压力对照，不应称作优化后的同频 ISAC 算法。
  3. 瓶颈：别把其他发射机干扰、本机发射泄漏、振荡器误差、ADC 动态范围和感知带宽混为一谈。子带划分只处理其中一部分；本机泄漏与回波在同一子带，保护带不能自动消除它。
  4. 创新：这是资源划分与系统集成的实验选择：两个 ZC 感知子带、一个 QPSK 通信子带。没有凭本页推导出自适应优化器、数字抵消增益或相干网络融合。
  5. 证据：§III–V、表 I–II、图4–10 用三台 X410，6.8 GHz、20 MHz、2048 格、128 μs 符号、1216 符号窗口，展示单站径向测速和通信。速度孔径来自时间，因而减少频率资源而保留相近测速表现有物理依据，但不证明同等距离分辨率或吞吐量。
  6. 边界：只有 SBFD 承载通信，图9 的 SBFD 有两条感知轨迹，基线有三条；任务和带宽均不匹配，不能读成公平通信性能排名。启动对齐小于 0.1 ms 不等于载波相干，也不证明多站飞行时间已校准；多基地感知仍是未来工作。
  7. 复现：先核对频格账本和理想模糊函数，再索取 IQ、真值、功率校准、估计器与重复试验分配。没有实测 IQ 和校准仪器，不能复现 BER、自干扰抑制或真实速度 RMSE。

作者报告的测量摘要

单站速度分辨率：0.145 m/s。速度 RMSE 的描述性区间：SBFD 0.1–0.3、多频带 0.2–0.4、同频 4–6 m/s；非严格极值、置信区间或单一汇总量，曲线含启动瞬态。NLoS QPSK BER：0.00363，仅为该设置的结果，没有匹配的通信基线。

通信链路端点仍需澄清：节点3被指定为通信发射机，而 §V-C 又把 USRP 3 写作接收机；不擅自补成某条链路。文中提到六次、每次五秒测量，但每种模式分别有几次不明确，不能据此写成 18 次或每模式六次。

02 / 同一组样本，两种孔径

距离沿频率匹配，速度沿时间匹配

固定一个单站孤立目标，理想时钟、线性接收机、无噪声、无多径，复信道幅度恒定。把候选距离或速度从真值偏移一点，再对复数相位求和。画的是归一化相干匹配功率，不是实空间目标、RMSE 或检出概率。

本页独立选择理想采样/网格带宽 Fₛ=20 MHz、N=2048，故 Δf=Fₛ/N=9765.625 Hz。Fₛ=B 是教学模型选择，并非论文提供的实测采样率。载频 f꜀=6.8 GHz，符号总间隔 Tₒ=128 μs，c=299792458 m/s。没有假设 Tₒ 等于有用符号时长；严格硬件复现仍需 CP 等参数。

Aᵣ(ΔR;K) = |(1/K) Σₙ₌₀ᴷ⁻¹ exp(−j 4π n Δf ΔR/c)|²
Aᵥ(Δv;M) = |(1/M) Σₘ₌₀ᴹ⁻¹ exp(j 4π f꜀ Δv m Tₒ/c)|²

n 是连续感知子载波的局部索引，m 是慢时间符号索引；ΔR 单位 m，Δv 单位 m/s。单站往返路径给出系数 4π；不能直接套到任意双基地几何。连续子带的起始频率仅改变公共相位，不改变这里的归一化功率。

距离峰到首零点：δR = c/(2KΔf)
相干观察时间：CPI = MTₒ
速度峰到首零点 / 理想格距：δv = c/(2f꜀MTₒ)

本页采用峰到首零点的名义分辨尺度；完整零点到零点主瓣宽度是它的两倍，不能混称。同样的格距并不保证同样估计精度：实际误差还受能量、噪声、加速度和相位噪声影响。子带越窄，距离主瓣越宽；M 不变时，理想速度主瓣不动。

04 / 从读懂走向研究

下一次对照，要固定哪几笔预算？

先固定总占用带宽、总辐射能量、观察时长和通信有效载荷，再问如何分子带兼顾距离与速度。可在明确的理想模型内求解，然后逐项加入 CFO、时延扩展或接收机非线性，并与相同预算的 TDD、同频正交码设计比较。这是研究提议，不是该论文的结果。

本页固定频格数量，不建模能量；归一化峰值隐藏了绝对信号强弱，不能宣称感知资源免费增加。理想频格正交不能预测保护带宽度到干扰抑制的曲线，也不预测 BER 或吞吐量。

硬件复核仍需：采样率、CP/有用时长、导频位置与数量、ZC 根、均衡器、杂波抑制、Doppler 估计与窗/重叠、滤波、CFO/SFO 处理、天线坐标与 RF 增益。另需分开记录回波功率、本机泄漏、其他发射机干扰、接收增益/削顶、信道估计误差、BER/BLER 和能源账本，并用匹配轨迹的重复试验给出不确定性。

原型中的主机启动同步、室内近距离设置不能外推为任意几何或室外覆盖；照片不能恢复精确坐标或通信 UE 位置。全文标题/叙述使用 FR3，但本页只使用实际载频 6.8 GHz，不据此制定规范频段定义。

证据范围：固定 v1 的 §II–VI、表 I–II、图4–10；三台 X410 的原型测量与本站独立计算分开展示。未复制原图、原始数据或实现完整硬件链路。
