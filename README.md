# ISAC 入门图谱

通感一体（Integrated Sensing and Communications）的中文图文入门网站。

**在线阅读：https://loonyreina.github.io/ISAC/**

## 内容

- 原理图解与历史时间线
- 单站、双站和网络化感知
- 带宽 / 观测时间与分辨率交互实验
- 研究方法地图与 OFDM 仿真实验建议
- 7 篇综述、原文链接和四周学习路线

## 本地预览

无需安装依赖或构建。在仓库目录运行：

```sh
python3 -m http.server 8000
```

打开 http://localhost:8000 。也可以直接用浏览器打开 `index.html`。

## 修改与协作

`index.html` 是网站的完整可编辑源码，包含正文、SVG 图示、CSS 和交互 JavaScript。

1. 从最新 `main` 创建分支。
2. 修改内容或交互；保留论文来源、模型假设、单位和图示说明。
3. 在桌面和窄屏检查页面；修改交互时验证滑块与数值输出。
4. 提交 Pull Request，说明修改内容、依据与检查结果；视觉修改建议附截图。
5. 合并到 `main` 后，GitHub Pages 自动部署。

网页端协作者需要此仓库的访问权限。查看文字可使用网页读取工具；检查实际排版和交互需要浏览器或截图工具。直接提交修改还需要仓库写入权限。

## 部署

GitHub Pages 使用 **Deploy from a branch → main → / (root)**。`.nojekyll` 确保直接发布静态文件。

该仓库是 GitHub Pages 版本的源码。之前发布的 Sites 版本独立维护，不会随着此仓库更新。
