# Point-target receiver integration, 2026-10-14

This additive teaching experiment takes a newly accepted current-session optimizer beam, constructs known finite DFT streams and actual complex noisy echoes, searches the full 18,001-point angular grid with unknown complex reflection coefficient, and reports 128-trial RMSE, bootstrap interval and the matching scaled CRB. It does not generate error samples from the CRB or use stored answers as a runtime result.

The independent numerical review covers accepted Nt4, Nt6 and Nt8/23° inputs, raw-Y likelihood, exact noise protocol, all trial estimates, the nuisance-parameter Fisher matrix, grid refinements and corrupt-record rejection. The dedicated independent CI vectors were generated in Python before loading the JavaScript implementation. Actual Worker/controller lifecycle tests cover cancellation, stale messages, source invalidation, input-only historical imports, export errors and bounded export timeout. These Node/VM/worker_threads checks do not establish native-browser performance, painted latency or hosted execution.

The new public namespace is `crb-receiver/`. Source is under `labs/crb-beamforming/receiver/`; mappings are explicit. A receiver-specific code-owned dependency gate runs alongside all existing module/classic checks against current output bytes. It binds every new script and stylesheet, the frozen existing model/data and four optimizer kernel dependencies, the private optimizer controller handoff, exact page load order, Worker constructor and every importScripts/require edge. Changing a script and updating its JSON hash still fails the code-owned gate. Unknown/moved namespace assets and missing endpoints fail closed.

Historical preservation helpers are used only at provenance read boundaries. They recover exact pre-integration bytes and the exact prior manifest; the live dependency scanners and current controller tests never receive that historical view. Original K=1 runtime, four single-user teaching sections, all existing page IDs, and four Eq(33) kernel bytes remain fixed. Historical Oct12 numerical and Oct14 optimizer browser evidence retain their dates and scope.

Run the complete source build with `node scripts/build-compatibility.cjs --test --reproducible`, the source-layout gate with `node --test tests/compatibility-build.test.cjs`, and then `node scripts/build-compatibility.cjs --check`. Receiver tests are registered in the actual aggregate/Pages entrypoints. Native-browser and deployment validation are separate release gates.

The experiment is limited to one point target, known waveform/channel, fixed beam, fixed model and finite trials. There is no extended-target browser optimization, clutter, multipath, original-paper comparator set, original Fig4 reproduction or hardware measurement. Cancellation or numerical failure does not fabricate final RMSE/CI; full finite large errors remain in the denominator. Optional full export is bounded at 8 MiB and is not rendered as page content.
