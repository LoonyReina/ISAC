## Updating and verifying

Update a stage only with its own source or executable evidence. Preserve historical fixture hashes and clarify their commit/scope; do not rewrite old checks as fresh runs. A reduced implementation must list missing branches and the exact selected experiment before the full-paper gate can move. Run the numerical reference before UI work; add fresh-input solving, failure/stale/cancellation behavior and measured desktop control-to-result latency only after the core gate passes.

Run `node --test tests/paper-execution-backlog.test.cjs` for the data contract. Coverage is derived from current canonical guides/catalog/case sources, not a permanent global count freeze. After the explicit compatibility manifest includes these artifacts, run `node scripts/build-compatibility.cjs --test --reproducible` for integration. These checks validate tracking structure and coverage; they do not reproduce any paper or certify its numerical solver.
