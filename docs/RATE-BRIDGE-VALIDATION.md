# 从符号判决到互信息与 CRB：验证记录

日期：2026-10-10。基线 `main`：`c62fd56b9782ea086e843ad34701481a50049fe6`。本增量不新增论文案例，不替换原有讲义或实验。

## 模型和教学边界

- `theory.html#rate-crb-bridge` 位于原 CRB 机制实验之后；两个接收角色、标签熵/BER/软互信息、实维度的 1/2 和两指标坐标依次展开。
- 通信：实标量 `Yc=X+Nc`，已知单位信道、未知输入实现，`gamma=1/sigma_c²`。感知：`Ys=theta X+Ns`，已知整块输入实现、未知固定无先验实增益，`sigma_s²=1`。噪声相互独立、跨样本独立且独立于输入。
- 两类输入均零均值、平均功率 1：等概率 BPSK 或独立 N(0,1)。无峰值功率限制，无逐块高斯能量归一化。
- `I_B=1-E log2(1+exp(-2 gamma-2 sqrt(gamma) Z))`；`I_G=0.5 log2(1+gamma)`。单位均为 bit / 实信道使用；不是复维度速率或硬判决后的互信息。
- `D_B=1/T`，`D_G=1/(T-2)`，T>2；单位为增益平方。不是某一估计器的实际 MSE。
- 图只有两个设计点，无连线、无填充，不计算完整 Pareto 区域或所有最优输入分布，不宣称普遍优劣。未计入峰值约束、编码开销、导频、带宽/吞吐量、信道估计或硬件损伤。

## 数值实现和误差

- `theory-core.js`：稳定 softplus `max(0,a)+log1p(exp(-abs(a)))`，复合 Simpson 确定性积分，默认 Z∈[-12,12]、步长 .01。API gamma∈[0,100]，零点返回精确极限 0；UI 是 -20…20 dB（gamma=.01…100）。UI T∈{3,4,8,16,32,64}，默认 8。
- 独立改变截断与步长：所有 41 个 UI SNR，固定步长 .01 比较 L=8/10/12；固定 L=12 比较步长 .04/.02/.01，差异均小于 4e-13 bit。测试没有同时改变二者来冒充独立收敛检查。
- 解析尾界：`softplus(-2 gamma-2 sqrt(gamma) z) <= ln2+2 sqrt(gamma)|z|`。用 `Q(L)<=phi(L)/L` 和 `E[|Z|1{|Z|>L}]=2phi(L)`，默认最坏尾界为 `2phi(12)(ln2/12+20)/ln2 = 1.2422081747404352e-30 bit`；它只约束截断，不代表总误差或浮点精度。
- γ=1：BPSK 0.4859441541329357、高斯 0.5；γ=10：BPSK 0.9967563279900297、高斯 1.7297158093186489。T=8 时 D 为 0.125 与 0.16666666666666666。表显示六位小数，高 SNR 的 BPSK 可能舍入为 1。
