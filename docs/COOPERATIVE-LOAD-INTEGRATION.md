## Scientific boundary

Independent fixed rational geometry, q=1, beta=2, 1–8 candidate stations. Other requests at each station are independent Poisson(m); the tagged request has a uniform rank among K+1 demands and is accepted when rank <= psi. The same accepted set participates in transmission and reception. All ordered pairs, including diagonal and reciprocal pairs, remain. This is not spatial network simulation, a joint multi-target allocator, Eq.16, a communication-rate integral, joint optimization, a physical receiver or source-figure reproduction.

The subset oracle enumerates rational geometry and exact rank; Poisson probabilities are numerical approximations with log-probability reporting. Conditional inverse-trace means include only identifiable subsets. Any positive outage probability gives an infinite extended unconditional bound. No pseudoinverse, clipping, inverse-of-mean replacement, or finite-sample convergence claim is made. Finite 32-bit simulation cannot resolve arbitrary rare events.
