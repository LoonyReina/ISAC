# 加权波形：总能量等式、真实求解与数值验证

日期：2026-10-12。固定原文 [arXiv:1711.05220v1](https://arxiv.org/pdf/1711.05220v1)，§IV 式(16)–(25)、Algorithm 1；原 PDF SHA-256 为 e79052feb8fd898002a71c9b1f20fd75cb757159b6e92071e97812e85b62d798。源 PDF 不随站点分发。

这是严格协方差分支之后的加权总能量分支。常模/相似性分支及完整原图仍未完成。本文只记录数值核心，不代替教学界面、真实浏览器和最终部署验证。

## 重要边界：原图3的加权曲线尚未复现

按原文公开的 N=16、K=4、L=20、Pt=1、iid CN(0,1) H、单位功率 QPSK、ρ=.1 运行256次配对试验，10/12 dB 的加权高斯对数速率诊断为12.882±.026、14.831±.038（Monte Carlo标准误）。固定原图的蓝色虚线标记经独立图像近似读取约为13.36、15.59，另有图像读取误差。差距约.48/.76 bps/Hz，大于本次统计标准误；这不是精确数字化曲线读数。严格分支的10.531/11.626则与原图约10.56/11.64接近。

因此，这批结果是明确未匹配原加权曲线的参数切片，不能称为图3复现。源公式、全局最优证书和独立SDP支持当前算法，但原图生成的实现/归一化细节尚未解决。没有调整ρ、能量或信号归一化来追图，也没有把差异归因于随机种子。

原始平均次数、随机种子、部分平均方式、ZF接收增益约定未披露。另用8组原参数输入、每组16种严格解零空间补齐，共128次加权重算验证：速率变化≤3.56×10⁻¹⁵，因此严格解自由补齐不能解释该全向曲线差异。原方向性R的目标宽度/网格/权重/约束、图5检测模型及图6角度MSE权重仍未恢复。

## 真正求解的对象

给定 H∈ℂ^(K×N)、S∈ℂ^(K×L)、X₀∈ℂ^(N×L)，求

    min ρ‖HX−S‖²_F+(1−ρ)‖X−X₀‖²_F
    s.t. ‖X‖²_F=L Pt，0≤ρ≤1

原文X₀来自相同H/S的严格协方差最优解。教学组合应重新调用既有严格求解器得到它，而不是接受导入记录中的旧X。低层核可接收任意X₀以验证一般数学问题，但这种输入不能自动宣称是完整原文构造。

约束是总能量等式，不是功率上界、固定空间协方差或常模。雷达目标是波形距离，不是方向图MSE或检测概率。速率只按逐用户残差计算高斯对数诊断；总MUI最小不一般等价于该非线性和最大，亦不等于QPSK互信息、BER或吞吐。

## 原算法与显式边界扩展

令Q=ρHᴴH+(1−ρ)I，G=ρHᴴS+(1−ρ)X₀。原文通过Q特征分解及标量世俗方程求解；实际使用复模平方。JavaScript把Hermitian Q写为[[ReQ,−ImQ],[ImQ,ReQ]]的2N维实对称表示，用完整Jacobi特征分解和有界二分求同一个方程，没有通用优化器替代、查表或预存最优X。

常规分支令t=λ+λmin>0，求Σ‖Zᵢ‖²/(qᵢ−qmin+t)²=L Pt。原文以一维搜索求此根；本站用二分，Python用Brent并另以二分核对。允许负λ；不能把λ强行限制为非负。

在最小特征空间上的G投影为零，且伪逆解能量小于预算时，根在边界，必须补入最小特征空间分量。原文Algorithm 1只列伪逆项，未明确该补齐；此处将其标为数学上必要的边界扩展。秩亏、零符号、零权重不是无解。Pt=0直接处理唯一可行X=0。

正定严格协方差X₀在ρ<1时保证G满行秩，理论上是常规分支；ρ=1的欠定通信端点则常需补齐。256次原参数试验全部有此情况：H†S平均能量6.686，低于预算20。若最低所需能量超过预算，ρ=1也可能保留MUI，不能自动称为零干扰。

## 端点补齐必须说明选择规则

canonical采用某个最小特征向量/时间坐标，确实达到主目标全局最优，却可能产生任意的雷达距离跳变。另提供radar-closest选项：在主目标同样最优的补齐中，让剩余能量方向对齐VminᴴX₀，进一步最小化‖X−X₀‖²。这是显式次级择优规则，不是原ρ=1主目标仍有雷达权重。

首个原参数输入在能量20、MUI约零的条件下，canonical距离34.0496，radar-closest距离.526147；ρ=1−10⁻⁸常规解趋近后者。旧任意补齐证据保留，不能把它画成必然的雷达代价。投影严格为零时所有补齐等距，非唯一性仍在；数值上低于阈值时只报告阈值下分类及误差界，不宣称数学上严格为零。

## API与证书

core.solve(H,S,X₀,ρ,Pt,{tieBreak:'canonical'|'radar-closest'})，复数为[实部,虚部]。核心N,K≤32、L≤128，输入幅值≤10⁶，块能量为0或[10⁻¹²,10¹²]；这些是实现范围，不是数学可行域。输入范围不符明确拒绝，不改动输入或自动加载。输出幅度只允许机器舍入级别的额外余量。

返回实际X、HX、XXᴴ/L、逐用户MUI、波形距离、加权目标、能量、λ、原文对偶值、KKT残差、特征分解残差/正交性、误差下界、补齐和阈值信息。独立验收重算提交X的目标和约束，不比较非唯一解的矩阵元素。

residualBoundGap是绝对全局最优性误差界，验收相对于objectiveCertificateScale（目标系数尺度），不一定相对于很小的最优目标值。应同时显示这两者。JS界显式计入特征分解重建/正交性造成的PSD误差；它是浮点数值证书，不是区间算术证明。任何非有限返回量或证书失败都不能显示为成功。
