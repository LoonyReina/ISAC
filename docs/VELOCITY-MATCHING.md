## 补上的逻辑

1. 区分第4步的固定子载波 H[m,k] 与第7步的固定距离 A[m,r]。
2. 先用实际前两拍计算 arg(z[1]conj(z[0]))，解释圈数/时间/速度；提醒单目标、相干和混叠前提。
3. 手动猜速度，第m拍反转m倍候选步长；实际复数相加而不是按真值画峰。
4. 对同一列评估不同候选；将每个规则候选的复数结果与原 Course.ofdm 的 D 矩阵对照。
5. 最后把它写成 DFT，说明 FFT 是算法、signed d 与数组 q 的区别、归一化、格距与不模糊范围。
