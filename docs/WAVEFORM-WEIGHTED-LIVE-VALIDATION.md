# 从同一 H/S/R 接入 Section IV 加权波形实验

日期：2026-10-12。本文记录共享输入模型、Worker 与教学界面的接入检查，不声明真实浏览器、线上发布或完整原图复现已经通过。

## 接入机制与未改变的内容

同一 `waveform-design.html` 保留严格协方差实验、原有27个明确标注的离线历史状态、历史数据及严格数值核心。新增 Section IV 实验使用原有 H/S/R 输入，不新增独立随机种子、维度、功率或可粘贴的 X₀。每个加权请求从当前 H/S/R 重新计算严格最优 X₀；一次扫描只计算一个 X₀，供所有权重共同使用。导入仍只读取顶层 H/S/R，忽略旧 X、X₀ 和记录内的旧加权结果。

严格核心 SHA-256 保持 `a844089a501bec61002fe8562f54314c04bc4f27b622033c3995052770b050c6`。独立审核通过的加权核心 SHA-256 为 `70f720a7f67f95b139f31171370d86e9e348bf9a91b4a0d0c38717a66cf5a6a3`。其数学范围和独立数值证据见 [加权核心验证](WAVEFORM-WEIGHTED-VALIDATION.md)。浏览器运行不依赖 Python、网络数值服务或预存最优波形。

新增模型层先调用未改变的严格解法，再将实际 H、S、X₀、ρ 和 Pₜ=tr(R) 传入加权核心。独立重算返回矩阵的 MUI、波形距离、能量、接收符号和空间协方差，并检查同能量候选 X₀ 的目标界。总能量是等式 ||X||²=LPₜ；加权结果不再要求协方差保持为 R，因此协方差变化是诊断而非失败判据。

默认 ρ=0.1，端点使用明确标注的 `radar-closest` 二级选择。`canonical` 仍可选；两者只有在相关边界/非唯一情形才影响输出。界面显示实际分支、补齐能量与阈值，不将数值近零投影说成精确非唯一性，也不将ρ=1说成必然零MUI。残差全局差界是相对于系数尺度验收的绝对目标界，不是相对于可能很小的最优目标的固定相对精度，更不是近病态边界处每个波形元素的一致性保证。

## 计算规模与失败边界

界面继续限制 N≤16、K≤8、N≤L≤64。一次运行只求当前ρ；扫描网格为 0、0.01、0.05、0.1、0.25、0.5、0.75、0.9、0.99、1。当前ρ不在网格中时另求该点，最多11个不同权重。网格连线只引导阅读，不代表未求解点的最优波形。

加权核心的幅度和能量范围比原严格手工输入分支更窄。超范围时，新增分支报告当前数值范围不支持，保留刚计算的严格结果，清空加权数组并禁用当前加权请求的下载。用户仍可单独运行和下载严格分支。没有改小严格分支的数学/数值输入范围，也没有把加权数值拒绝写成球面不可行。

其中界面测试执行真实控制器脚本，但使用可控制回复顺序的 DOM/Worker 替身；它们不是渲染浏览器、键盘或辅助技术验收。实际 Worker 脚本另在独立 VM 环境执行，覆盖静态资源载入、计算、进度和完整请求 SHA-256。

数值实现方另对实际包装层执行 Python 复算：12组新 H/S/R、24个请求、252个点，覆盖两种端点规则与ρ=1−10⁻¹⁰；按参考求解器系数尺度归一的最大目标差2.34×10⁻¹⁴，能量相对残差1.69×10⁻¹³。两项加权范围拒绝均保留新严格结果且没有加权数组。该次模型源码 SHA-256 为 `b282e2cd303f1a49e7bdf51b184e68b5f65e05177f599f990b570bc743bd04eb`。这些检查不替代独立界面和浏览器审核。

## 取消、过期结果与记录

每个请求有递增身份；完整请求指纹包含 H/S/R、ρ、端点规则和扫描开关。修改这些输入立即终止 Worker，清除旧图、证书、矩阵及下载资格。不同ρ的迟到回复即使 H/S/R 相同也不能恢复旧结果。部分扫描进度不可导出；失败时不保留一条省略失败点的曲线。

改变 SNR 只重新计算当前实际 X 的逐用户高斯对数诊断，X 和求解目标不变。严格阶段最小化总 MUI，加权阶段最小化ρC+(1−ρ)D；两者都没有将非线性和速率或BER作为优化目标。改变用户、天线、矩阵选择和窗口尺寸不重新优化。

本地JSON保留顶层H/S/R供重新导入，另保存当前严格X₀、全部加权X/HX/协方差、每点指标、ρ/端点选择、种子、两个核心身份、输入及完整请求散列、证书和阈值、当前诊断值、耗时与范围说明。下载前再次核对当前输入和加权参数，不能导出过期结果。

保留旧 `endToEndMs` 字段及其明确范围：输入已完成生成/解析与边界检查后，至接收并核对Worker结果；包含Worker启动/计算/传递，不包含输入准备、绘图或下载。此处没有把它改称点击到绘制完成的浏览器端到端测量。
