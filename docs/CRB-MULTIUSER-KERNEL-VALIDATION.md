# CRB 多用户点目标：离线数值验收

这是实际执行论文式(33)的多用户点目标求解器，输入新的复数信道后重新优化并恢复波束。不是单用户公式替代，也不是查表或插值。

## 已通过

- 独立复核194项断言：32次独立执行、3组新CVXPY对照、完整物理SINR/Fisher/对偶界重算
- 12组新小阵列用例全部通过；另1组Nt16/Nr20/K4/Γ15dB原尺寸用例通过
- 固定同一H和资源，Γ0/5/10/15/20dB的5次新求解全部通过；不同种子用例不能连成取舍曲线
- Worker取消、替换、旧结果隔离等14项检查通过；Node VM另测了浏览器代码分支
- rank(H[a,ȧ])=2是显式数值门槛；10,000组秩亏探针无错误满秩判断

## 必须保留的限制

当前仅通过有界离线数值门槛。没有实际浏览器延迟、教学UI、生产或整篇论文验收；扩展目标求解器尚未移植。验收使用公开浮点容差，不能改写成精确全局最优证明。只有status=converged且physicalGate.passed=true才能显示为已接受波束。

初版ρ=1时的4个迭代封顶结果仍保留，其中原尺寸用例20,000次迭代耗时80.69秒。确定性条件调整ρ=clamp(Γ,1,100)后最终重跑通过，不改变信道、功率或噪声。发现的CRB数值溢出和秩诊断消差问题均已修复并保留前后证据。

最终小阵列Node耗时25.3–730.2毫秒，中位数57.8毫秒；原尺寸单例5.67秒。它们不是浏览器控件到结果延迟。

首个教学范围建议：Nt4/6/8、Nr=Nt+4、K2、L30、P1000mW、两类噪声1mW、alpha1；显式运行/取消，固定H比较Γ0–20dB。0dB仍是Γ=1。normalizedInformation不是旧单用户页面的g。没有已验证的浏览器原文双基线，不应添加虚构性能排名。
