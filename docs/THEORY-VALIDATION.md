## 2026-10-10 · 标量 CRB 交互增量（基于上述 PR #7）

改动：在既有静态算例旁添加一个独立机制实验，保留共享模型和其余页面。两个新图（前64块能量、累计 CRB 均值）由同一数值核心生成，包含理论叠线、汇总表和全部绘制检查点的数值替代。可选 T=3/4/8/16/32/64、B=100/2000/10000，默认种子2026，手动重采样及重置；无自动播放、外部依赖、参数上传或新服务成本。

随机机制：32-bit LCG + 开区间 uniform 的 Box–Muller，伪随机且可重复；每次从种子重置，同一 T 下增加 B 保留前缀。计算复杂度 O(BT + B log B)，上限640000个实高斯样本；排序只为经验分位数。图最多160个均值检查点包含首尾，未绘出的中间值仍参与所有统计。没有以曲线平滑代替计算。
