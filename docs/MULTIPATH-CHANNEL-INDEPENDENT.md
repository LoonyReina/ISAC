## 独立性与覆盖范围

Python 参考此前通过独立高精度、直接复数和及连续积分检查；本次直接运行实际 JS，并同时使用两类预期值：

1. 冻结 Python 参考的完整样本、复响应、功率、最大点和状态
2. 审计程序自己写出的欧氏几何、直接 RF 频率传播相位、逐候选复指数求和、分数时延波形及 DFT、单位化 IDFT、逐 Fourier 交叉项 CP 积分

没有把 JS 的解析核当作它自己的数值答案。14 个场景包含全部 9 个发布夹具及额外的端点、混合参数和共同相位对照；比较全部 128 个 Y 和全部 1401 点 z/功率，不只比较少数截图读数。

额外检查涵盖：101 个高度的反射几何与相等角度、给定时延 Gram 的严格别名及近别名、最小正 binary64 分离量、全部数值资源字段、同一预算下的相长/相消、相同/别名时延代数夹具、精确并列取最小候选、精确零信道无估计。

接收机隔离测试在内存中给几何、增益、生成器、解析核和诊断函数加入抛错语句，再给接收机输入已生成的 Y/X/f/固定网格。输出与原接收机逐项相同；没有改写磁盘上的实际核心。额外真值候选、改变的导频和频率网格会被拒绝。

## 主要实测数值误差

这里“误差”仅指不同计算路径的浮点数值差，不是测距误差或定位性能。

| 检查 | 最大绝对差 |
|---|---:|
| 实际 JS 全部 Y 对 Python | 2.74×10⁻¹⁵ |
| 独立 RF 频率计算，载波只计一次 | 6.14×10⁻¹⁵ |
| 实际 JS 全部 z 对 Python | 2.48×10⁻¹⁴ |
| 实际 JS z 对独立逐候选复数和 | 3.01×10⁻¹⁶ |
| 实际 JS 功率对 Python | 3.12×10⁻¹⁵ |
| 分数时延连续波形 → DFT → Y | 3.25×10⁻¹⁵ |
| 几何与反射角 | 1.78×10⁻¹⁵ |

所有普通场景的最大点索引、精确并列数和响应状态一致。Gram 测试的 log κ 和正常范围 λmin 与冻结参考一致；复非对角项最大差 1.74×10⁻¹⁸。长至约 99 个别名周期的低级核压力测试采用较宽的绝对容差，不能把该范围误标成有效 CP 几何场景。

独立得到的连续 CP 能量约为 0.219222411485584，复制 32 个数字样点的 CP 能量约为 0.219012438986954。二者分别与实际 JS 一致；不能都替换成 0.25。完整突发时长、固定接收窗口、最大绝对时延、频带端点、名义 DFT 带宽、候选网格和固定纵轴也通过检查。

## 审计发现并修复的数值守卫问题

1. **稀疏数组**：JavaScript 的 map/some 会跳过空洞，旧实现可能接受缺失候选并给出 undefined 最大值。现在统一要求每个位置有自身索引；继承来的数组项也不能替代输入样本。Y/X/f/候选/路径/系数/功率/墙段均受检查；每个复数对内部的实部和虚部也必须是自身索引，不能从原型继承。
2. **未知参数键**：错拼或未支持的资源键现在被明确拒绝，不会悄悄沿用默认值。
3. **提前倒数溢出**：极小 X 的能量可能使 1/E 先溢出，尽管最终商可表示。实际匹配器改用分量直接除以 E，并检查非有限结果。
4. **正信号数值下溢**：正的路径幅度若已舍入成零增益、零分量样本，或非零 Y/z 的平方全部下溢成零，不能报告物理无响应。现在抛出 `RangeError`，携带 `BINARY64_RANGE_LIMIT` 与明确的数值范围说明。测试覆盖 b=10⁻¹⁷⁰、最小正 binary64 的 b/ρ，以及外部给定的极小非零 Y。

这些守卫根据实际浮点下溢/溢出事件触发，没有增加任意的物理 epsilon 截止。普通物理夹具结果不变。b=ρ=0 和纯代数完全相消仍然返回真正的 `no_response` 与空估计。
