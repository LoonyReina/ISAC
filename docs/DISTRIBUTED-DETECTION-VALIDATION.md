# 两站检测与统计压缩：验证记录

日期：2026-10-11 UTC。课程入口：`distributed-detection.html#question`。

## 1. 机制和证据边界

本站是独立的二站、固定候选、已知白噪声、已知反射先验的边缘化高斯 LRT。它对未知随机反射 α 积分，不是 Behdad 等原文的 MAPRT，也没有复现论文图、功率优化、未知 target-free 通道、杂波、真实网络或定位结果。

- 同一参数点的三个处理器共享两站原始复观测、波形、能量、时长、噪声和统计先验
- 原始样本与局部复匹配输出具有同一个似然比；正交残差在当前已知噪声模型下相消，不是原始数据可逆压缩
- ρ>0、κ=0 时，两个功率之和已经足够；κ>0 时，相同功率可以支持不同的复数 LRT 判决
- 局部匹配能量和只是可解析基线，不能代表最优能量消息检测器；后者一般还依赖能量乘积的贝塞尔项
- 改变 κ 是改变已知分布，不是从当次两支箭头估计相关性，也不是移动接收站
- ρ=0 时，Q 恒零；核心要求调用方显式给独立 U 才作随机化。页面不制造确定性单次 Q 判决，曲线使用 Pd=Pfa
- κ=1 的反射先验可秩一，但含独立噪声的观测协方差始终正定；运行路径使用非负特征形式，不求逆奇异先验
- 账本按两站星型单播计实标量，同时计模板和明确输入的模型下行；缓存历史成本、校准维护、包头和网络时延没有被设为免费

Behdad 固定官方来源为 [arXiv:2305.12523v2](https://arxiv.org/abs/2305.12523v2)，修订日 2024-03-27；§VII 式(20)–(33) 为最大化型 MAPRT。§IX p.11 的数值设置为独立反射，不是本页 κ>0 例子。Zou 2024 只核对出版身份，未核验稳定官方 / 作者全文，不作公式级归属。详细边界见 `data/distributed-detection-sources.json` 与 `scripts/distributed-detection-reference/SOURCE_BOUNDARIES.md`。

## 3. 实际 JavaScript 实现

`distributed-detection-core.js` 无第三方依赖；核心只接受观测、已知模型和门限。`generateObservations` 是独立生成器接口，目标标签与抽样 α 不会返回给检测函数。实际原始接口利用已证明的充分压缩，测试另外使用完整 2L 维复 Cholesky 密度核对。

运行域：ρ=0 或 [10⁻¹⁰,10⁴]；κ∈[0,1]；Pfa∈[10⁻¹²,1−10⁻¹²]；1≤L≤4096；波形能量和复噪声功率各在 [10⁻⁸,10⁸]。拒绝非有限数、空输入、缺项数组、不支持的微小正 ρ 与伪造模型；不悄悄裁剪或替换成零。

数值路径使用稳定 log-tail、小量级数、log1p/expm1、归一化分位数求解及独立计算的漏检率。不同指数权重不会因接近而吸附成相等；主统计量使用非负特征和，矩阵交叉项表达只用于审计。

JS 端明确处理：CDF 的零输出为 +0；Wilson 区间在 0 / 全成功时保留精确端点。生成器在 E=10⁻⁸ 或 10⁸ 的 sqrt/square 舍入可能越界时，仅把生成波形幅度向域内移动一个可表示步长；不裁剪用户观测。所有 L=1…4096 的生成端点均被测试。

### 精确十进制夹具不等于 binary64 输入

独立夹具用精确十进制参数。输入 0.999999 与 0.999999999999 被 JS 解析为 binary64 后，与精确十进制有微小差别，尾概率接近 1 时可放大小门限的相对差。仓库测试对这一输入差异使用明确容差，同时在实际 binary64 输入上严格核验校准。不得把输入编码差异误判为校准失效，也不能用宽容差代替实际输入的精确 oracle 对照。

## 4. 页面交互与记录合同

默认 A/B 是两组人为构造、能量相同的观测。每组先产生两站各 16 个原始复样本：已知波形投影加固定正交残差，然后重新匹配；原始与压缩接口使用同一组 y。曲线来自解析分布，不是对这一个确定性观测作“准确率”估计。

- 控件分开 ρ、κ、Pfa；κ-only 按钮保持 ρ，包括 ρ=0
- 可输入四个 I/Q 分量；没有把生成器 α 或 H 标签塞给接收机
- 两条曲线显示共同原始 / 复匹配方法和能量和基线；每点都用自身 H₀ 分布按相同 Pfa 校准
- 图外参数保留真实数值，只省略图内当前点，不裁成边界；ρ=0 不伪造有限 dB
- 原始预览由既有 `experiment-record.js` 限至 12000 字符；完整下载保留 32 个原始复样本、波形、71 点 Pd、61 点 ROC、门限与账本
- 缺脚本或非法输入时清空旧图、读数、预览，并禁用下载；改回合法值或恢复默认可继续
- 原生带标签控件、默认关闭进阶、无动画；窄图将两个等尺度 I/Q 坐标上下排列
