# 同方向论文对读：实现与验证记录

日期：2026-10-11 UTC。Node：v24.19.0。基线：`5ac20bcba9a8abfd38aaf960b404a1b34c21eaef`。工作分支：`feat/beamforming-paper-comparison`。

## 本轮交付

在生成的 `reading.html#paper-comparisons` 中接入一组既有论文：2018 分离/共享阵列、2020 联合通信/雷达流、2022 CRB 波束设计。入口位于研究方向之后、影响证据目录之前。没有新增论文、数值模型或性能排名。

- 三张并列问题卡和独立绘制的 HTML 信号路线，分别说明信号、可用阵元与设计目标；箭头只是阅读顺序
- 三种问题视角、三种拟比较前提，以及一个带逐选项来源反馈的学习判断
- 原生 details 内保留固定版本、精确定位、原文资源、方法条件、未知与失败样本处理
- 学习入口、实验、原文、边界、资源模型和空白主题笔记的原生链接
- 控件初始化前隐藏；静态来源、全部解释和下一问无需 JavaScript 仍可阅读

实现由 `site/registry.json` 的 `paperComparisonGroups`、`scripts/paper-comparison-groups.cjs` 和仅在阅读页加载的 `paper-comparison.js/css` 组成。生成器只增加五个明确的阅读接线点。没有网络请求、存储、上传、历史改写、自动滚动、科学求解器或外部依赖。

## 来源与科学边界

论文身份和教学路线取自既有 case/unit；本组真正检查的原文版本、URL、定位另存于每个成员的 `inspectedSource`，不能默默沿用旧课版本。

1. 2018：固定 [arXiv:1707.00519v1](https://arxiv.org/pdf/1707.00519v1)，2017-07-03，使用预印本 PDF 页码；既有课的 UCL 期刊 VoR 信息原样保留，本轮未重新核验 VoR
2. 2020：固定 [arXiv:1912.03420v2](https://arxiv.org/pdf/1912.03420v2)，2020-02-02；保留角度 RMSE、GLRT 检测仿真与被省略的未检出案例，2018 基线只称一个 SSP 惩罚型变体
3. 2022：固定[作者托管期刊 VoR](https://www.weizmann.ac.il/math/yonina/sites/math.yonina/files/Cramr-Rao_Bound_Optimization_for_Joint_Radar-Communication_Beamforming.pdf)，印刷 pp.240–253；点目标通信流与扩展目标辅助探测流分开，单用户功率等价特例保留已知/未知、资源和非零信息条件

完整参数、求解器和原图未复现。2022 对照基线是否保留/改动原每天线约束仍未充分核实。2018 PR/N 印刷归一化的条件核算不推断作者实际程序。选择最完整前提也只得到计划，不认证公平比较已经完成。没有复制论文全文、原图或 PDF。

独立原文与 UX 源码审阅未报告阻断项；这不是浏览器交互、视觉或无障碍认证。
