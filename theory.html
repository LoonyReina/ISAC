01 / 两条基础线

通信和雷达各自先解决什么？

这是一条贯穿原有 18 章的理论路线，不替换已有实验。每一站都有问题、出口和继续阅读的位置。

  1. 共同工具：从电压到样本

    先问：接收机为什么能把一个真实电压变成 I/Q 两个数？复数、采样、卷积和频谱各描述哪个操作？

    出口：能区分瞬时幅度、归一化功率与一段信号的能量；知道 FFT 是计算某种投影的方法。

    从 I/Q 与复包络开始 →

  2. 通信：恢复人为写入的信息

    链路：比特 → 编码与调制 → 信道 → 同步/信道估计 → 均衡 → 符号判决/译码。

    出口：知道解调需要哪些先验；区分一次判决、统计误码率、实际速率与容量上界。通信也估计信道，只是最终任务通常是恢复消息。

    重建 OFDM 通信接收机 →

  3. 雷达：判断并解释环境改变

    链路：已知发射 → 反射与传播 → 匹配 → 检测 → 参数估计 → 跨时刻跟踪。

    出口：从单站往返几何得到 τ=2R/c，再学速度与方向。知道峰值不等于检测通过，分辨率不等于估计精度，CRB 不是算法误差。

    回波与几何 →检测 →性能语言 →

  4. 汇合：观测、未知量和似然

    共同结构：由候选参数生成一个预测观测，再问它与实际样本有多一致。白高斯噪声下，这变成平方误差/匹配问题。

    出口：能够给 Y、H、X、N 分配角色，而不是看见同一个式子就断言两个任务完全相同。

    亲手切换“未知的是符号还是延迟” →

  5. 系统与演进：共享的收益和代价

02 / 共用的数学结构

Y = HX + N：到底在求谁？

先给变量分配角色，再选择估计器。这里用有限长度实基带例子，不假装已经覆盖复数 MIMO、连续延迟或真实硬件。

Y 是实际接收数据，X 是发射信号，H 是传播的线性作用，N 是噪声。窄带平坦信道中 H 可以是一个复增益；多径离散时域中 H 可以是卷积矩阵；OFDM 近似成立时可逐子载波写成 Y[k]=H[k]X[k]+N[k]。这几个 H 的表示不同，不能把所有传播问题都缩成一个标量乘法。

通信：消息未知

给定同步和已知/估计的 H，比较不同 X 对 Y 的解释。训练阶段也可能先用已知导频估 H。

本实验：已知波形 s、延迟 d、增益 α=1 和相干相位参考；只判决 b∈{−1,+1}。

感知：传播参数未知

给定实际发射 X，利用 H(θ) 的结构估计 θ。单站已知发射的条件不能直接套到未知数据的被动接收机。

本实验：已知 s 与 b=+1；延迟 d 和实增益 α 未知。搜索 d 时，每个候选都重新拟合 α。

用同一段样本，构造两种问题

y[n] = α b s[n−d] + ε[n]，　n = 0,…,31
ε[n] 独立同分布 ~ N(0,σ²)，　Ts = 10 ns

s 是 13 个 ±1 组成的 Barker 序列，窗口外补零；离散能量 E=Σs²=13。所有幅度均归一化、无量纲，σ 是每个实样本的噪声标准差，不是 dB 或 Eb/N0。这里的样本间隔只是离散模型的时间刻度，不据此声称连续时间带宽或测距分辨率。

  1. ① 已知条件已知整段发射 s
  2. ② 未知量延迟与实增益
  3. ③ 候选模板对每个候选拟合增益
  4. ④ 决策与单位最大得分 → 延迟 → 距离
受控实验 · 改变未知量，保留生成模型
接收机任务

通信接收机得到此延迟；感知估计器只得到观测 y，不得到真值 d。没有时钟偏差、运动、多径或窗外截断。

默认 σ=0 是无噪声最小二乘检查点。固定种子方便公平对比；“换噪声”才更换样本。真实生成增益始终为 1。

为什么两种任务不能直接使用同一种得分？

独立同方差实高斯噪声下，固定 σ>0 时 log p(y|μ)=常数−‖y−μ‖²/(2σ²)。所以最大似然就是比较残差。σ=0 时不使用高斯密度公式，直接看无噪声/最小二乘极限。

通信：b̂ = arg minb∈{−1,+1} ‖y−bsd‖²
感知：α̂(d) = sdᵀy / E，　d̂ = arg maxd |sdᵀy|² / E

sd 是延迟 d 的完整 32 样本模板，所有候选均有 E=13，因此图中的感知得分额外除以 E，不改变排序；通信得分取负残差再除以 E。不能把两种模式的得分数值直接当成同一性能指标比较。

通信的增益和相位已知，+s 与 −s 必须区分。感知允许未知实增益，所以先为每个延迟拟合 α，再比较解释的能量；如果允许任意复增益，就把转置改成共轭转置 sᴴ，得到 |sᴴy|²/‖s‖²。若通信同时不知道任意复增益和符号，单次观测通常不能把符号旋转与信道相位区分开；需要导频、结构或其他约束。

先预测：无噪声，选错延迟一格，为什么得分降低？

正确延迟时 13 个符号同号相乘，sᵀy=13，图上得分为 13²/13²=1。延迟错一格，Barker 序列的相邻非周期相关为 0，得分降为 0。不是接收机知道真值，而是该模板不能解释观测。离散格距 10 ns 对应单站 1.5 m；本实验没有推导连续延迟估计精度或物理分辨率。

能从这个实验得出什么？

可以验证已知条件怎样决定搜索空间、匹配怎样来自似然、未知增益怎样改变评分。不能由一次噪声样本估计 BER、检测概率或 CRB；不能将最大峰值自动视作目标存在。下一步回到 匹配滤波、OFDM 七步 与 检测阈值。

模型参考：Zhang 等，2021，§II–III；Xiong 等教程，v2，§IV。Barker 离散例子、归一化和图形由本站独立推导实现，不是论文实验复现。

03 / 技术为什么演进

每一步，都是在回答上一种方案的局限

这是设计逻辑图，不是互相取代的年代排名。专用、共存和联合设计至今仍有各自适用条件。

分立 → 共存

既然共用频谱，先让彼此不受伤害

分时、分频、空间隔离和干扰管理保留各自波形。好处是职责清楚；代价是隔离资源、协调开销和剩余干扰。它还没有要求“一次发射做两件事”。

两条并行路线

雷达波形嵌入信息 ↔ 通信波形提供测量

雷达中心设计以测量为主，在波形参数中携带数据；通信中心设计利用 OFDM 等已知符号估计传播。问清优先目标、有效吞吐量和感知可用性，再比较方案。

联合收发设计

既然都要做，能否共同选择波形与波束？

在总能量、频谱、天线、功放和时延约束下寻找性能区域。更好的某个工作点不是“两项任务都免费变好”；应与公平基线、单任务端点及时间共享比较。

互助与网络化

从共享设备走向共享知识

感知结果辅助波束选择，通信网络辅助同步、节点协作与信息融合。资源共享的集成收益，与任务互助的协同收益，要分别计量；定位、隐私、开销和不确定性开始进入闭环。

04 / 从讲义走向论文

读一篇论文，留下七个能被核验的答案

不以“用了什么新名词”作为创新判断。先写清旧方法为何不足，再检查作者的证据究竟证明了什么。

示范论文：Xiong 等，On the Fundamental Tradeoff of Integrated Sensing and Communications Under Gaussian Channels，arXiv v8（2023-06-07；首稿 2022）。这是理论权衡案例，阅读入口可先用 配套教程 §IV。

  1. 问题：共享发射信号时，通信速率与感知参数估计界能达到怎样的区域？先写清两端接收模型、谁知道发射实现，以及估计哪个参数。
  2. 基线：通信最优端点、感知最优端点与两端点时间共享。比较前固定带宽、总平均功率、时长、天线和先验；否则“收益”可能只是资源增加。
  3. 局限：通信偏好有利于传递消息的随机输入，感知关心已知实现产生的信息矩阵；仅固定平均协方差，未必固定平均估计界。
  4. 创新：用 CRB–rate 区域研究子空间权衡和确定性–随机性权衡。创新判断要定位到新定义、推导条件和区域结论，不只复述缩写。
  5. 证据：端点界、渐近/高 SNR 分析与数值区域属于理论及数值证据，不是硬件实测。复述任何结论时保留它的条件。
  6. 边界：向量高斯信道、感知端精确知道发射 X、选定的估计界和通信速率定义。CRB 约束估计问题，不保证某个算法在有限样本/低 SNR 时达到它。
  7. 复现：先抄明模型、维度、随机分布、约束与目标函数；复核端点和最小例子，再复现一张指定版本的图。记录种子、参数、数值容差、试验数及失败条件；本站下例只复现一个数学机制，不声称复现整篇论文。

第二个论文案例：导频省下来，距离为什么重复？ 从稀疏 OFDM 观测、真实导频图与距离匹配，进入参考信号图样设计。

第三个论文案例：时钟差 10 ns，位置差多少？ 从互易标量时延、双基地椭圆与镜像歧义，进入网络 ISAC 联合估计。

第四个论文案例：分的是带宽，测速看的是时间 从 SBFD 原型的资源账本，分清频率孔径、时间孔径与匹配实验对照。

一个能在纸上核验的机制：平均信息相同，平均下界未必相同

设 yᵢ=θxᵢ+nᵢ，θ 为待估的无量纲实增益，nᵢ 独立 ~ N(0,σ²)，每块 T 个已知发射样本。对给定 x，Fisher 信息 J(x)=Σxᵢ²/σ²，因此条件无偏估计的 CRB(x)=1/J(x)。

固定幅度、随机正负号

xᵢ=±√P，每块能量恒为 TP，仍可通过符号承载信息。

E[CRB] = σ²/(TP)
T=8，P=σ²=1 → 0.125

独立高斯幅度

xᵢ~N(0,P)，块能量波动。对 T>2，利用卡方分布的倒数期望：

E[CRB] = σ²/[P(T−2)]
T=8，P=σ²=1 → 1/6 ≈ 0.1667

两者平均 J 都为 8，但 E[1/J] 不等于 1/E[J]。这里的 CRB 单位为增益平方；这个标量教学推导不证明 BPSK 在完整 ISAC 系统中普遍优于高斯输入，也没有同时算出通信容量。若论文结论依赖“平均”二字，就追问平均发生在求逆之前还是之后。

研究机制实验 · 先逐块求逆，再跨块平均

先预测：两类输入具有相同的平均样本功率 P，为什么增加块数后，高斯输入的平均 CRB 不一定靠近 BPSK 的水平线？只改 T，再观察差距。

本实验固定 P=1、σ²=1，均为归一化幅度平方；θ 是每块内固定、无先验的实增益。T 是每块的实样本数；B 是独立发射块数，增加 B 只改善 Monte Carlo 统计，不增加单块观测时长。只抽取已知发射 x 的实现并计算条件 CRB，不生成估计器误差，也不绘制通信容量。

每次计算从显示的种子重置。相同设置与种子得到相同结果；只增加 B 时保留旧的样本前缀。BPSK 的正负号不影响能量，因此直接绘制精确 TP，不额外抽取无关符号；没有强制每个高斯块归一化。

推导与边界：为什么是 T−2？

条件对数似然对 θ 的导数为 Σxᵢ(yᵢ−θxᵢ)/σ²。利用独立噪声的方差 σ²，得到 J(x)=Σxᵢ²/σ²。BPSK 的能量恒定，因而 1/J=σ²/(TP)。高斯输入的 Q=Σxᵢ²/P 服从自由度 T 的卡方分布。

E[Q⁻¹] = Γ(T/2−1) / [2Γ(T/2)] = 1/(T−2)，仅 T>2
E[1/J] ≥ 1/E[J] = σ²/(TP)

积分在 Q=0 附近只有 T>2 才收敛。T≤2 时，高斯 E[CRB] 发散；任意有限模拟出现有限平均值也不能证明它收敛。控件因此限制 T≥3。T=3、4 的均值存在，但 CRB 方差仍发散，不能给普通有限方差标准误或据此声称正态置信区间。即使 T>4，稀有的低能量块仍可能让短模拟波动。

这是本站独立实标量、无先验教学推导。原论文的向量/复数模型、先验信息、通信目标与最优区域均不在这里复现；本实验也不证明 BPSK 对完整 ISAC 系统普遍更好。
