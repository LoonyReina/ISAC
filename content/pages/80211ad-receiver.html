怎样成为雷达接收机？

先看真正收到的 I/Q，再检查：有没有捕获到帧，相关峰落在哪，跨帧相位怎样给出表观速度。出现峰、通过门限与物理正确，是三件不同的事。

这是同一篇 802.11ad 雷达论文的算法续读。原有孤立 Golay A+A / A+B 机制实验保持独立。数值及 Node Worker 已核验；实际浏览器性能、设备内存和完整无障碍实测仍待验证。

接收机拿到什么？不知道什么？

已知模板，未知回波

通信端知道自己发出的完整前导。模拟器生成固定分数时延、未知复反射系数、多普勒加振荡器偏移，以及有限 RRC 有色噪声。接收机使用原始样本、已知模板、采样参数和已声明的噪声方差；目标真值只进入生成与最后评估。

τ = 2R/c；fD = 2v/λ；λ = c/fc
回波相位 = exp(+j2π(fD + fosc)t绝对)

单站低速窄带模型，v>0 表示接近。正相位与正速度保持一致；I/Q 是复包络，不是射频瞬时电压或目标位置。

真实前导，明确重构

固定芯片速率 1.76 GHz、载频 60 GHz、β=0.25。STF=[16×Ga128, −Ga128] 共 2176 芯片；CEF=[Gu512,Gv512,−Gb128] 共 1152 芯片。物理 π/2 芯片旋转在分数时延成形之前。

信号是截断理想 RC 的采样；噪声由独立归一化有限 RRC 滤波。这里没有执行两段有限 TX/RX RRC，也不把其级联当作完全相同。Ga/Gb 的标准专用 D/W 递推与最终反转不同于先修页的通用递推。

实际调用顺序

第一帧能量选采样相位 → STF 自相关捕获 → 全前导初步时延 → lag128 合并频率 → 帧内去旋转相关 → 局部 CEF 与 Moose → 未去旋转 CEF 的慢时间 DFT。

诊断处理在捕获失败后继续。接受状态只要求 STF 与匹配检测共同通过。论文 v1 假设完美 CFO 补偿；此处显式估计合并频率是实现扩展，不是源文的 CFO 稳健性证明。

先修顺序：I/Q → 完整模板匹配 → 孤立 Golay 机制 → 原文 CEF 边界 → 相位与速度
