研究案例 / 严格协方差下的波形设计

方向图相同，
通信符号为什么不同？

给出通信通道 H、目标符号 S 和雷达空间协方差 R，现场求出发射块 X。先看每个矩阵代表什么，再检查结果是否真的满足约束。

复数矩阵同预算比较全局最优证书

01 / 先理解作者解决了什么

固定照向哪里，不必固定每一列怎么发

四根天线同时发射八个复基带样本。每一列是一个时刻的四路 I/Q 系数，每一行是一根天线的时间序列。空间方向图取决于这些行之间的平均相关性，并没有把八列的排列和相位全部规定死。

通信有另一种要求：已知两位用户的通道后，希望八个时刻的接收复数分别靠近预定 QPSK 符号。只设计雷达方向图的波形未必做到这点。2018 年论文的关键是：把这两个要求放到一个明确优化问题里，在严格协方差约束下用一次奇异值分解获得全局最小的符号匹配误差。

先预测：如果两个发射块的 XXᴴ/L 完全相同，功率方向图会不同吗？它们经过同一 H 后的 HX，也一定相同吗？先写下你的预测，再看实验。

先修：I/Q 与复数、阵列与方向。本页需要矩阵乘法与共轭转置，但会说明每一步对应哪个物理对象。

02 / 写清观测、已知量与约束

要优化的是发射块 X，不是接收机的估计值

Y = HX + W；X ∈ ℂᴺˣᴸ，H ∈ ℂᴷˣᴺ，S ∈ ℂᴷˣᴸ
入门默认 N=4，K=2，L=8，Pₜ=1；实际维度随输入显示；设计误差 E(X)=||HX−S||²ꜰ

H 是已知、块内不变的窄带下行线性通道；若习惯写单用户 yₖ=hₖᴴx，则 H 第 k 行已是 hₖᴴ，计算 HX 时不能再取共轭。S 是已知目标符号，X 是待设计变量；上标 ᴴ 表示共轭转置，||·||ꜰ 是所有复数绝对值平方之和再开方。实验直接画无噪声 HX，未抽样 W。

Rₓ = XXᴴ/L = R_d，tr(R_d)=Pₜ
aₙ(θ)=exp(jπn sinθ)，n=0,…,N−1；P(θ)=aᴴRₓa

Rₓ 是发射样本协方差；其迹是 N 根天线合计的平均功率 Pₜ，块能量为 LPₜ。默认 N=4、L=8、Pₜ=1 时，块能量为8。L 仅表示块内快拍数；这里没有指定采样周期或物理带宽，不能从序号换算秒数或距离。ULA 阵元间距为半波长，θ 从阵列正前方计。图中 P(θ) 是原始归一化功率，使用不除以 √N 的导向向量；不对每条曲线各自峰值归一化。

R_d(β,θ₀) = (Pₜ/N)[(1−β)I + βa(θ₀)a(θ₀)ᴴ]
现场生成器 0≤β≤0.95；历史对照 β∈{0,0.4,0.8}，θ₀∈{−30°,0°,30°}

这是本站透明的合成目标协方差，不是原文三方向最小二乘雷达设计。β=0 时 R_d=(Pₜ/N)I，方向图恒为 Pₜ；入门默认 N=4、Pₜ=1 时才是 I/4 与恒为1。β 增大时把空间功率集中到 θ₀，但总平均功率仍为 Pₜ。β<1 保证正定，L≥N 使满秩协方差可实现。θ₀ 是照射方向，不是通信用户的物理位置。

04 / 为什么一次 SVD 就能全局最优
把协方差固定，把时间方向转到最合适的位置


对正定 R_d 作下三角 Cholesky 分解 R_d=FFᴴ。写 X=√L FZ，则严格约束等价于 ZZᴴ=I。Z 有 N 行、L 列，行彼此正交且各自单位范数；它控制剩余的时间方向。


E(X)=L tr(HR_dHᴴ)+||S||²ꜰ−2√L Re tr(ZᴴC)
C=FᴴHᴴS ∈ ℂᴺˣᴸ


前两项已经固定。降低误差就是提高 Z 和 C 的复数内积。做薄 SVD：C=UΣVᴴ，其中 U 为 N×N，Vᴴ 为 N×L；奇异值 σᵢ≥0。复数迹不等式给出 Re tr(ZᴴC)≤Σᵢσᵢ。取 Z*=UVᴴ 便达到这个上界，且 Z*Z*ᴴ=I。


X*=√L FUVᴴ
E*=L tr(HR_dHᴴ)+||S||²ꜰ−2√L Σᵢσᵢ(FᴴHᴴS)


上表的 E−E* 就是直接算出的符号误差与该理论下界之间的差。最优解接近0的差值是数值检查；全局性来自上面的迹不等式，不来自随机搜索次数。当 K<N 时，rank(C)≤K 是结构性的秩亏证据。原文 N=16、K=4 至少需要补齐12个零空间方向，否则会少发能量并破坏满秩 R。不同正确实现可以给出不同 X，应比较目标与约束。页面显示的数值秩另依赖阈值；数值上小不等于严格为零，不能只凭数值秩宣称非唯一。


为什么这个基线公平，却不是论文全部基线？
Z_ref[n,m]=exp(j2πnm/L)/√L
X_ref=√L FZ_ref；Z_ref Z_refᴴ=I


参考选择 L 点单位 DFT 的前 N 行，也满足相同 R_d 和 LPₜ。它故意忽略 H、S，隔离出“时间方向对通信符号的影响”，不是通信算法的强基线。这里没有以多给功率换取误差改善，也没有与违反严格协方差的通信 ZF 混排。全局最优只指这个确定性的约束最小二乘问题。


05 / 与原始研究逐项对照
论文不只画一个好看的方向图


固定原文：Fan Liu、Longfei Zhou、Christos Masouros、Ang Li、Wu Luo、Athina Petropulu，Toward Dual-functional Radar-Communication Systems: Optimal Waveform Design，IEEE TSP 66(16)，4264–4279，2018 年8月。公式定位采用 2017-11-14 的 arXiv v1（预印本标题为 Towards）；固定版本 PDF。


  • 问题与模型：§II，式(1)–(7)，把通信多用户干扰 / 符号误差与发射雷达协方差放在同一 X 上。本站保留已知 H、S 和窄带复基带模型。
  • 严格设计：§III，式(8)–(15)，从全向约束走到给定方向协方差，用正交 Procrustes 和 Cholesky 变换得到闭式全局解。本站交互实现这一机制；符号推导使用 N×L 薄 SVD 形式。
  • 原文图3–4：§VI 的通信性能与雷达方向图数值比较，采用 N=16、L=20、K=4、Pₜ=1、单位功率 QPSK、复高斯信道和半波长 ULA；方向性参考针对 −π/3、0、π/3。本站可以现场运行这一全向参数切片，也提供小维度与单方向混合协方差。一个随机块不是图3–4；独立256次配对实验也只是明确披露的全向切片。原文三方向 R 的设计细节、ZF归一化/接收约定与平均设置尚未闭合，未声称复现整图。
  • 后续方法：§IV 将通信误差与波形偏差加权，式(16)起进入带总能量约束的权衡；§V 常模设计进入另一类非凸问题。本站不实现这两部分，不把严格解当作常模解。


创新落点：把一般“共同发射”的想法变成可精确求解的波形层问题；严格方案保住指定的空间协方差，同时寻找更好的逐符号通信匹配。放松雷达约束以及加入常模硬件要求时，求解结构发生变化，不能沿用本页的一次 SVD 结论。

06 / 什么没有被这次成功证明
相同方向图，不等于相同的全部雷达能力


  • 协方差确定这里的空间发射功率，但不确定延迟–多普勒模糊函数、距离旁瓣或具体接收处理性能。本页没有目标、杂波、检测器、CRB、RMSE 或虚警率模型。
  • E/(KL) 是每个复数样本的确定性匹配误差，包含增益失配及残余多用户干扰；它不是误码率、容量、编码速率或估计误差。更小 E 不自动证明所有这些指标改善。
  • 满秩 R_d 要求 L≥N；N>1 时 β=1 会失去 Cholesky 所需的正定性，因此选择器统一限制 β≤0.95。N=1 时 R_d=Pₜ，与 β 无关。每个天线每个时刻的幅度可变，总能量约束不等于逐样本常模，也没有峰均比或功放约束。
  • 假设 H 完全已知，S 已知且可联合设计整个块；没有信道估计误差、频率选择性、OFDM、RF 约束或实时计算成本模型。
  • 现场比较只在同一组 H、S、R、N、K、L 内成立。历史27状态不是 Monte Carlo 统计；新随机块也不等于跨环境统计结论。


下一研究问题：通信拟合变好，距离旁瓣是否变坏？
先固定当前 H、S、R_d、L 和能量，用 X_ref 与 X* 的实际时间序列计算同一种匹配滤波器的延迟相关旁瓣。再问：只用协方差约束是否足以保障你关心的雷达任务？这是下一项待做的研究，不是本页已经验证的结论。若进一步加入常模约束，应重新写可行集，并建立新算法与新最优性边界。
