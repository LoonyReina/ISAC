01 / 单用户特例 · 把物理对象放在前面

一次发射，两处接收

“波束”是发射天线各自使用的一组复数权重：决定每根天线发多大、相位是多少。这个单用户特例只有一路通信符号，8 根天线把同一份符号按不同权重发出。雷达也用这份已知信号照射目标。

  2. 02

    1 位通信用户

    接收数据与噪声。要求有用信号功率与噪声功率之比，至少达到指定门槛。

    通信要守住什么
  3. 03

    1 个目标，12 根接收天线

    目标反射信号；接收阵列从天线间的相位变化估角度。反射的幅度与相位未知。

    雷达想知道什么

没有其他信号流来干扰用户，所以主实验使用 SNR（信噪比）。目标位于阵列正前方 0°，这是用于局部设计和评估的观察方向；我们不假装已经从数据发现了目标。

先分清指标

CRB 是给定观测模型下、满足正则条件的局部无偏估计的方差下界。为了让角度单位更直观，本页显示它的平方根：角度标准差下界，越小越好。它不是实测 RMSE，也不保证某个估计器能达到。

现在先猜一猜：通信要求慢慢变高时，这个下界会立刻上升，还是先保持不动？

03 / 看懂变化，而不只看曲线

没用完的余量，不需要提前牺牲

Ⅰ

还有余量

朝目标最有利的波束，已经满足用户需求。门槛提高一点，最优波束仍不用变。

Ⅱ

开始取舍

原波束不够用了。必须重新分配天线权重；通信刚好达标，雷达保留的信息逐渐减少。

Ⅲ

超出能力

即使全力满足用户，也只能达到 20 dB。更高的要求有严格不可行证明，不是算法没找到解。

这里的“一开始不变”很重要：两种任务共享资源，并不意味着任何通信要求都会立刻伤害感知。只有约束真正开始限制最优解，才出现取舍。另一方面，改变 ρ 是在换一个信道场景，不能把不同 ρ 的结果当成同一场景下的算法增益。

一个必须单独处理的端点

把 ρ 设为 0，门槛设为 20 dB：通信仍然可行，但目标正好落在零陷中。此时完整 Fisher 信息矩阵奇异，常规角度 CRB 不可用；从可辨识的内部趋近这个点时，下界发散。这与“通信不可行”是两件事。

再问一步：反射系数未知，为什么要扣掉一部分角度信息？先理解物理原因，再展开 Fisher 信息

角度变化会让回波发生变化，但回波变了，不一定能完全归因于角度。一个未知的反射系数，也能改变整段回波的幅度和相位。估角度时，必须去掉这部分可以被“换一个反射系数”解释的变化。

这个单用户特例的一路信号经过固定波束后，在目标处只留下一个复数系数。它随角度发生的局部变化，与未知反射系数混在一起；接收阵列各天线之间的相对相位变化仍然提供角度信息。因此不是“所有信息都被扣掉”。

默认当前波束：已知系数的信息 13259.0321 rad⁻²，混淆损失 939.6663 rad⁻²，有效信息 12319.3658 rad⁻²。

观测中的每个符号是什么

X 是 8×64 的已知复数发射样本块；Y 是 12×64 的复数回波；α 是整块共享、未知的复反射系数；Z 是独立圆对称复高斯噪声。a 与 b 分别描述发射、接收阵列在角度 θ 的相位。

Y = α A(θ)X + Z，A(θ) = b(θ)a(θ)ᴴ，R = XXᴴ/L

估计的三个实参数是 θ、Re α、Im α。导数对弧度求取，并把已经选好的 X 和波束 w 固定；不能把“每个角度重新设计波束”的变化混进接收观测导数。ᴴ 表示共轭转置。

S₀ = tr(AᴴAR)，S₁ = tr(ȦᴴAR)，S₂ = tr(ȦᴴȦR)
c = 2|α|²L/σR²
J已知 = cS₂，J损失 = c|S₁|²/S₀
J有效 = J已知 − J损失，CRBθ = 1/J有效

这来自三参数实 Fisher 矩阵消去两个反射系数参数后的 Schur 补，对应期刊式 (7)。要求 S₀>0 且有效信息为正；零照射时不能把 0/0 或伪逆值冒充常规 CRB。每个复噪声样本的功率是 σR²，其实部、虚部方差各为 σR²/2，因此公式有因子 2。

为什么单用户特例的照射强度与 CRB 恰好一致

一路信号给出秩一协方差 R=wwᴴ。对于居中接收阵列，只要目标照射非零，发射端的导数项恰好全部被未知 α 吸收：

J有效 = c‖ḃ‖² |aᴴw|²
CRBθ = σR² / (2|α|²L‖ḃ‖²|aᴴw|²)

所以在这个特定单流模型中，把目标照得更亮，确实等价于把角度 CRB 变小。这不是对所有波形、接收模型或未知参数都成立的结论。下方可选实验会改变波形族，展示它的边界。

想手算：为什么这条曲线是精确最优解？两维空间、两段公式与一个可行性上界

先构造两个正交、单位长度的空间模态。u 给各天线相同权重，指向正前方；v 的权重沿居中天线序号线性变化，左右反号。它们是权重向量，不是两个人所在的位置。

m = −3.5, −2.5, …, 3.5
u = (1, …, 1)ᵀ / √8，v = m / √42
h = ρu + √(1−ρ²)v，‖h‖ = 1

用户接收 yₗ=hᴴwsₗ+zₗ，单位符号功率下 SNR=|hᴴw|²/σC²。这个单用户特例的 Γ 是线性门槛，Γ=10ΓdB/10；“无最低要求”时 Γ=0。对固定总功率 P，Cauchy–Schwarz 不等式给出严格上界：

γmax = P‖h‖²/σC² = 100 = 20 dB
q = Γ/γmax；q ≤ 1 才可行

只对 a 与 h 张成的空间内分配功率即可；垂直于这片空间的分量既不帮通信，也不帮目标照射。于是最大化目标照射可以精确化为两个系数的选择，不必扫描几条候选波束。

g = |aᴴw*|²/(NₜP)
q ≤ ρ²：g* = 1
ρ² < q ≤ 1：g* = [ρ√q + √(1−ρ²)√(1−q)]²

第一段的 w*=√P u；第二段的最优权重可直接写成：

w* = √P(cᵤu + cᵥv)
cᵤ = ρ√q + √(1−ρ²)√(1−q)
cᵥ = √(1−ρ²)√q − ρ√(1−q)

别混淆两种“方向”：方向图横轴 ψ 是物理观察角度；cᵤ、cᵥ 是两种天线权重的混合系数。改变系数会改变方向图，却不能把系数的混合角当作某个真实用户或波束的指向角。

平台结束于 γmaxρ²；平台内实际 SNR 可以高于要求，取舍区恰好等于要求。ρ=1 时，全部可行门槛都在平台；ρ=0 时 g=1−q，q=1 是前文单独处理的奇异端点。

CRB* = CRB₀/g*
√CRB₀ × 180/π = 0.4766007952°
ρ=0.5，Γ=18 dB：g*=0.8524180021
√CRB* × 180/π = 0.5162124281°

CRB₀ 是只有雷达目标时的最优方差下界，单位 rad²。开方后乘 180/π 才转成度；方差本身则乘 (180/π)²。上述全局最优性针对已声明的单用户、单流、点目标模型，对应期刊定理 1 的特例。

检查公平性：单用户特例固定了哪些资源和假设？

以下均为本站合成、归一化教学参数，不是照搬原论文的仿真设置，也不是校准过的真实链路预算。

  • 发射 Nₜ=8、接收 Nᵣ=12，均为居中半波长均匀线阵；孔径分别为 3.5λ、5.5λ；窄带、远场、单站点目标
  • 设计与评估角 θ₀=0 rad（正前方）；单个目标的角度未知，延迟、多普勒及其他目标参数不在本实验中共同估计
  • L=64 个复数快照，总平均功率 P=1，总块能量 LP=64；不是每根天线等功率约束，也不是每根天线瞬时常模约束
  • 通信信道精确已知、范数固定为 1；通信噪声 σC²=0.01；雷达每个复样本的噪声功率 σR²=100
  • 真实 α=1+0i 只用来评估局部下界，估计器并不知道 α；所有比较保持它和噪声不变
  • 主实验一路已知波形，示例样本块满足符号能量恰为 L，因而 R=XXᴴ/L=wwᴴ 精确成立；没有把有限随机块自动当成集合平均

对于任意 n 根天线，居中序号 m 从 −(n−1)/2 到 (n−1)/2。导向向量每项模为 1，并没有除以 √n：

aₘ(θ)=exp(iπm sinθ)，ȧₘ(θ)=iπm cosθ·aₘ(θ)
‖a‖²=Nₜ，‖b‖²=Nᵣ
θ₀=0 时：Dₜ=‖ȧ‖²=42π²，Dᵦ=‖ḃ‖²=143π²

导数单位是每弧度。增加快照数 L 而保持 P，会增加总能量 LP；本页不把这种收益说成固定总能量下的免费提升。与上一页的每天线等功率模型比较前，也必须先对齐约束。

04 / 从一个用户走向两个用户

先问回波告诉了我们什么，再问怎样分配波束

上方是可手算的单用户特例。下面保留一个点目标，换成两路数据、两个通信接收机，真正重新求解原文式 (33) 的协方差优化问题。

角度有一点变化，已知发射信号的回波也会改变。改变得越容易与噪声区分，局部角度信息就越多。但回波变了，也可能是反射幅度或相位变了；不能把两种解释都算作角度信息。

这里展示的是理论精度边界。CRB 的单位为 rad²；先开平方，再乘 180/π，才得到以度表示的角度标准差下界。它不是接收机已经达到的 RMSE，也不是分辨率或检出率。下方波束优化器只计算设计与下界；取得验收波束后，可继续生成带噪回波并运行接收机，检查真正的 RMSE。

多一位用户，多了什么困难？

用户 1 想接收第一路数据，第二路到达它的接收机时就是干扰；用户 2 的角色正好交换。雷达知道两路发射样本，可以共同利用它们的回波。这个点目标分支没有额外添加独立探测流。

→

→
用户 1：数据 1 + 干扰 + 噪声用户 2：数据 2 + 干扰 + 噪声点目标 → 雷达接收阵列

这是信号关系示意，不是空间位置图。这里的 H 是一般复数信道，不能凭矩阵元素推断用户的角度、距离。两路符号不相关，也不意味着另一位用户的波束在接收端自动为零。

SINRk = |hkᴴwk|² / (Σi≠k|hkᴴwi|² + σC²)
有用信号功率 /（其他数据流的干扰功率 + 噪声功率）

每位用户都必须达到最低 SINR，同时两路波束共用一个总平均发射功率预算。先固定信道和资源，再提高共同门槛，才能观察通信要求怎样限制感知设计；重新抽信道或增加天线是在改变实验条件。

查看或编辑复数信道 H，保存与载入记录

怎样保证比较公平，又该怎样理解这两个数字？
  • 误差不是下界的随机抽样。先构造 X=WcS 和真实复数回波 Y=αA(θ)X+N；接收机在全部 18,001 个角度拟合未知 α，返回全局网格最大值。真值只用于生成与最后计算误差，不用于接收机选峰。
  • 资源固定，接收 SNR 单独变化。S 的两行采用确定的有限长 DFT 序列，使 SSᴴ/L=I₂ 精确成立。这是受控符号构造，不是假称有限个独立随机符号自然正交。四点比较只改变 α，并对同一试验编号复用完全相同的噪声。
  • 尺度对齐。雷达 SNR=|α|²LP/σR²，其中 P 为 1000 mW 预算，不额外乘阵列增益。这里的 √CRB 已按接收 α 缩放，不能直接拿上方 α=1 的设计下界与低 SNR 的 RMSE 比。
  • 分母完整。RMSE=√(Σ(估计角度−真值)²/128)，不是平均有符号误差。所有有限估计，包括端点和超过 5° 的错误，都计入。只要有数值失败或未完成试验，就不提供该条件的最终 RMSE 与置信区间。
  • 下界有适用范围。CRB 是本模型下局部无偏估计器的方差下界；网格 ML 有有限样本、偏差与低 SNR 选错峰现象。实测 RMSE 略低于 √CRB 不会被截高，也不单凭这一点判为错误。区间来自 1,000 次确定性 bootstrap；128 次和一个固定信道不构成普遍排名。
  • 这是有限范围教学实验。未加入杂波、多径、校准误差、未知发射波形或扩展目标；阵列、用户数与原文图 4 不同，也没有原文算法基线。改变上方参数、重新求解、导入或离开页面，都会使接收结果失效。

06 / 看清真正运行的优化

先设计协方差，再恢复能发射的波束

多用户没有沿用单用户的两段闭式公式。每次运行都把当前复数信道送入后台 Worker，求解原文式 (33)，再检查恢复后的实际波束。

  1. 1 · 把波束写成协方差

    Wk=wkwkᴴ 表达第 k 路的空间功率与相关性；正半定表示任何测试方向的功率非负，并非每个矩阵元素都是正数。

  2. 2 · 同时照顾信息和约束

    用一个 2×2 Schur 条件表达有效角度信息，把两位用户的 SINR 和总功率写进同一个半正定优化问题。

  3. 3 · 恢复两路发射权重

    优化先放松秩一要求；只有秩条件、恢复残差与物理检查支持时，才能把协方差答案作为原波束问题的数值答案。

  4. 4 · 从波束重新验算

    用恢复的 Wc 重算每位用户 SINR、总功率与 CRB，并核对信息值到对偶上界的差距。仅“收敛”还不够。

固定设计，才对观测求角度导数

两路数据组成 S，Wc 的两列是 w₁、w₂，发射块 X=WcS。原文使用单位符号协方差的理想化；若构造有限块，只有明确满足 SSᴴ/L=I₂ 时，R=XXᴴ/L=Σkwkwkᴴ 才精确成立。有限个独立随机符号不会自动精确满足这个等式。上方优化器先求设计协方差；接收机扩展再用固定有限 DFT 符号构造真实回波。

Y = αA(θ)X + Z，A(θ) = b(θ)a(θ)ᴴ
s₀ = tr(AᴴAR)，s₁ = tr(ȦᴴAR)，s₂ = tr(ȦᴴȦR)
c = 2|α|²L/σR²
J已知 = cs₂，J损失 = c|s₁|²/s₀
J有效 = c(s₂ − |s₁|²/s₀)，CRBθ = 1/J有效

Y 为 Nᵣ×L 的复数回波；Z 的复样本噪声功率是 σR²，实部和虚部方差各占一半，所以 c 中有因子 2。未知实参数为 (θ, Re α, Im α)。对三参数 Fisher 矩阵消去 α 的两项，即得到上述 Schur 补。这里的扣除是参数混淆的精确消去，不是人为加的惩罚项。

公式要求 s₀>0 且有效信息为正；具体浮点计算还要通过数值可辨识性检查。准确的解析奇异与近奇异的保守拒绝须分开解释。ȧ、Ȧ 对弧度求导，保持这次设计的 X 固定，不能把“每个 θ 再优化一次波束”的变化算进观测导数。

当 s₀>0 时，2×2 条件使 t 不超过 s₂−|s₁|²/s₀。放松的是原先 rank(Wk)=1 的约束；并非换个变量名就自动解决了原问题。定理 2 还要求可行性与 rank(H[a,ȧ])=2。诊断记录给出两奇异值、相对阈值和每路秩一恢复残差。

程序内部采用归一化信息坐标以改善数值尺度。它的 normalizedInformation 不是前面单用户的 g，也不是“相对仅雷达最优值”；教学图使用物理 J有效（rad⁻²）。恢复信息与对偶上界必须在同一尺度比较，带符号差距和容差保留在记录中。

成功表示本次浮点结果在声明容差下通过检查，包含恢复后的 SINR、总功率、Fisher 信息与对偶差距。它不是区间算术证明，也不是作者的 CVX 软件。计算上限、秩条件拒绝、数值失败和有证据的不可行是不同状态。

固定资源、阵列约定与“角度已知”的含义
  • 当前范围：K=2；Nₜ=4、6、8，Nᵣ=Nₜ+4；L=30；P=1000 mW；σC²=σR²=1 mW；α=1+0i；共同 Γ=0–20 dB；θ₀=0° 或 23°。
  • 两阵列都是居中半波长均匀线阵，窄带、远场、一个点目标。Nₜ 改变时，发射与接收孔径都改变，不是免费增益。此处没有指定真实距离、带宽或快照时间间隔。
  • 总功率约束允许天线之间不等功率，也不要求瞬时常模。L 个快照下，LP=30000 是按快照计的能量比例；未指定采样时间，不能直接称为焦耳。提高 L 而不降低 P 会增加总观测能量。
  • α=1+0i 是评估下界时声明的真实值，接收机仍把复 α 当未知量。θ₀ 是已知的局部设计方向，待估 θ 是未知参数；模拟真值与接收机搜索区间是另外两个概念。接收机扩展按所选雷达 SNR 改变 α，并独立搜索整个视场。
  • 一般复数 H 被精确已知；没有校准误差或信道估计误差模型。当前范围不保证每个自定义 H 都可行、满足定理条件或在计算预算内通过验收。

当前只读的数值与资源边界

一次只运行一个 Worker；每次求解最多 20000 次迭代、30 秒。三门槛比较逐次求解，也可停止。30 秒是防止长时间占用的资源上限，不是浏览器延迟承诺；达到上限表示尚未取得验收结果，不证明不可行。

08 / 带走结论，也带走边界

好下界的前提，是说清楚已知什么、未知什么

这页最值得带走的，不是某个角度小数，而是三个判断：约束何时开始起作用；“要求不可行”与“估计模型奇异”怎样区分；方向图之外还需要哪些接收信息。

本页只处理一个点目标与精确已知信道；局部设计方向固定，接收机仍搜索整个视场。单用户闭式特例、双用户数值优化与带噪接收试验各有声明预算。接收扩展提供固定信道下有限 128 次的实际角度 RMSE；没有距离或多普勒估计、检出率、虚警率、分辨率、BER 或射频非理想。若加入额外未知参数、改变波形是否已知、给反射系数先验，Fisher 信息必须重新推导。

下一问

下界更小，接收机在噪声里就一定估得更准吗？

不一定。CRB 描述局部可辨识模型的方差下界，实际估计还会受到低信噪比、搜索与大误差的影响。现在可以在本页接收试验固定已验收波束，生成带噪观测，让不知道真实 θ 与 α 的接收机全视场选峰。对照同一组噪声的四个 SNR，观察大误差计数和 RMSE 何时接近局部下界。
