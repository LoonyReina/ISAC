阵列资源 / 空间零干扰的代价

同样八根天线，
分开使用会少掉什么？

一半发用户数据，一半照向目标。如果还要求雷达信号完全不打扰用户，补回发射功率后，目标方向也能恢复原来的强度吗？

先看物理对象，再手算一次相消。主实验只改目标方向；共享阵列、边界和原文推导可以逐层展开。本页没有求架构最优解。

01 / 先数物理资源

天线没少，单份信号能用的范围变了

固定一排 8 根发射天线，相邻间隔半个波长 λ/2。用户在正前方；目标在另一个方向。默认把左 4 根交给独立雷达符号 s，右 4 根交给用户数据 c。改变每根天线的复数权重，就是同时改变它发出的幅度和相位。

8 根天线，8 条理想复权重发射路径，总孔径 3.5λ；分离时雷达和通信各用 1.5λ 子孔径，共享数据可用 3.5λ。

这里一根天线对应一条理想全数字 RF 发射路径，RF 路径数不是信号流数。分离是 1 条数据流 + 1 条独立雷达流，共享是 1 条数据流 + 0 条独立雷达流。没有计算真实硬件成本、接收 RF 链或功放效率。

同一预算：总平均发射功率 P=1；分离时雷达 0.5、通信 0.5；共享时一份数据使用 1。带宽、符号时间与观察时段相同，均未指定 Hz 或秒。用户噪声功率固定 0.05。

02 / 先手算一次相消

用户方向安静，不等于每根天线都不发声

暂时只看一个独立的两天线小例子。正前方的用户收到两路同相叠加。让雷达权重分别为 +1/2 和 −1/2：

发射账

|1/2|² + |−1/2|² = 1/2

两根天线都在发，平均总功率是 0.5。

用户方向账

1/2 + (−1/2) = 0

先加复数幅度，再平方。相位相反，所以这个方向的雷达项为零。

若另一方向的传播相位恰好再给第二路一个负号，收到的幅度就变成 1/2+1/2=1，方向功率为 1。这不是凭空增加总功率，而是不同方向的相干叠加不同。

方向功率不是把所有角度的曲线值直接相加得到的“总发射功率”。总预算始终按各天线平均功率之和计算。

带着这个问题往下看：如果用户和目标几乎在同一方向，让用户听不见雷达，会不会也让目标听不见？

03 / 先比较分离子阵的 A 与 B

消掉干扰，再把功率补回来

A：左边雷达子阵直接朝目标，右边通信子阵朝用户。B：先从雷达权重中扣掉会进入用户方向的那部分，再把雷达平均功率恢复到 0.5。B 有定义时，A 与 B 都实际发出总功率 1。

只改变目标方向，用户固定 θ=0°。相邻天线的导向相位差为 πu；滑块等间隔改变 u，角度 θ 的步长不相等。范围 −0.9–0.9；可在输入框使用 1e-12。精确输入是计算依据，滑块只是近似位置。

默认 u=0.25 刻意选为 8 元全阵的一对正交方向：八路相位贡献相加为零，并不是两个方向相差 90°。它方便看出差别，不是典型随机信道。通信门槛 Γ=20（约 13.01 dB）。

A · 分离，不置零

直接朝目标发独立雷达符号

总功率 1；用户 SINR≈2.2135；目标总照射≈2.8536。

目标：雷达 2 + 通信 0.8536。

B · 分离，置零后补功率

恢复雷达预算，不恢复原权重方向

总功率 1；用户 SINR=40；目标总照射=2。

目标：雷达 1.1464 + 通信 0.8536。

用户收到了什么？

用户收到自己的数据、未知的独立雷达符号和噪声。三项先分开算平均功率：D 是想要的数据，Iᵣ 是雷达干扰，σ² 是噪声；本页只有一位用户，没有其他用户干扰。

A：2/(0.8536+0.05)≈2.2135，未过门槛。B：2/(0+0.05)=40，通过门槛。

中间步骤 / 只作功率诊断

刚投影完时，其实少发了一些功率

把原单位雷达权重投影到“用户听不见”的空间，剩下的能量比例叫 q。此时还没补功率，不能放入同预算排行榜。

q≈0.5732；雷达平均功率从 0.5 降到 0.2866，整体只发 0.7866。

把幅度乘 1/√q≈1.3208 后，雷达功率回到 0.5；目标雷达照射只从 0.6572 变成 1.1464，仍小于 A 的 2。

raw 表示未补功率的投影，只在灰框和完整记录里出现，不绘成同预算主方向图。

功率回来了，目标方向却未必回来

下面横轴是相对正前方的角度 θ，纵轴是发射方向功率 aᴴRa，线性范围固定 0–8。A 为橙线，B 为青绿线；竖线分别标出用户与目标方向。不按各条曲线的峰值归一化。

默认 4+4 分组：B 雷达目标照射变弱；通信仍贡献 0.8536，所以总照射是 2。

04 / 如果八根都发同一份用户数据呢？

共享消掉的是独立雷达项，不是所有取舍

共享时 x=wc，所有天线都发送同一份用户数据 c。雷达复用这份数据探测；没有另一个独立符号 s，因此没有独立雷达干扰项。这不是让用户消除一个已知雷达符号。

C · 共享，朝用户

SINR=160；目标方向功率理论为 0。

D · 共享，朝目标

目标方向功率=8；用户 SINR 理论为 0。

默认 C 把数据送给用户，却恰好在目标方向形成零点。没有独立雷达干扰，不等于两个任务都完成。

在相同 0–8 线性坐标下比较四种明确配方：橙 A、青绿 B、蓝 C、紫 D。所选共享配方加粗，另外一条仍保留。B 未定义时不画它，也不拿别的波束冒充 B。

默认 B 与 C 都通过通信门槛，B 在目标方向更强。保持 4+4 分组、让两个方向重合时，C 的目标照射为 8，A 为 4，另一个严格零干扰见证为 2；此时 B 未定义。这只能说明几何与配方会改变结果。某个配方失败，不证明该架构的所有设计都无解。

与 2020 联合波束成形课分开读：那一页在共享阵列上另加独立雷达流；本页的 2018 共享模型只使用通信符号。

05 / 亲手碰到边界，并检查每天线功率

“未定义”“不可行”“没过门槛”是三件事

总共仍是 8 根，但每份信号的子孔径随分组改变。雷达和通信预算仍各为 0.5；用户信道始终从同一全阵信道截取，不对子阵另行归一化。

边界按钮同时恢复标注的分组：前三项与“4 元正交”均使用 4+4；“只有 1 根”使用 1+7、u=0.5。

当前投影可归一化；严格置零子空间的维数为 3。

  • 精确重合且 Nᵣ>1：目标导向的投影为零，B 的 0/0 归一化未定义，但零空间仍存在。另造一个相消波束可以花满雷达预算，只是它对重合目标的雷达照射也为零。
  • Nᵣ=1 且非零用户信道：零空间维数为 0，正雷达预算与严格零干扰不能同时满足；这是当前固定分组子问题不可行。
  • 非常接近：q 很小但为正；补功率倍数很大，最终雷达功率仍是 0.5，不表示 RF 输出无限增大。

总功率相同，是否就有相同功放要求？

下图逐根画 B 的实际平均功率 Rₘₘ。虚线 1/8=0.125 只是假如额外要求每天线相等时的参照；本模型只约束总功率，没有每天线相等、每天线 1/8 上限、常模或瞬时峰值约束。

默认 B 最大每天线功率≈0.20210，大于 0.125；不能声称满足相同的每天线额定上限。

固定 4+4 且功率各半时，B 的总目标照射恰好恒为 2（B 有定义时）。这是雷达损失和通信照射变化的特殊抵消；改成 6+2 就没有此恒等式，不是雷达能力保持不变。

06 / 用复数权重和协方差把账写清楚

每个公式对应哪个物理量？

m=0,…,7；u=sin θ；aₘ(u)=exp(jπmu)，导向向量不除以 √N，所以 ‖a‖²=N。目标和用户处于窄带远场半波长 ULA 的同一合成 LOS 几何中。用户信道 h=√g exp(jφ)a(u用户)，本页 g=1、φ=0.37；假设发射端完整、精确知道 h。没有把子阵信道重新归一化。

用户收到 y=hᴴx+n。c、s 都是零均值、单位方差、相互独立的复符号。这里算集合平均协方差；有限个独立随机符号不保证样本交叉项恰为零。原论文采用 hᵀx；令本页 h 等于原文信道的共轭即可等价，不能再重复共轭。

分离：x=w꜀c+wᵣs；R=w꜀w꜀ᴴ+wᵣwᵣᴴ
共享：x=wc；R=wwᴴ
D=|hᴴw꜀|²；Iᵣ=|hᴴwᵣ|²；SINR=D/(Iᵣ+σ²)
总预算 tr(R)=ΣₘRₘₘ；目标照射 T=a(u目标)ᴴRa(u目标)

分离两因子在物理天线上的支撑不重叠，因此 R 为块对角。共享的同一数据横跨全阵，R 可以有跨块相关。共享只保留一个因子 w，Iᵣ=0；单用户也使多用户干扰为 0。

投影 q 为什么也决定目标损失？

在雷达子阵上，令 bᵣ=aᵣ(u目标)/√Nᵣ、bᵤ=aᵣ(u用户)/√Nᵣ。Π=I−bᵤbᵤᴴ 去掉用户方向；v=Πbᵣ，q=‖v‖²。A 使用 √Pᵣbᵣ；raw 使用 √Pᵣv；B 在 q>0 时使用 √Pᵣv/√q。

A 的目标雷达功率：PᵣNᵣ
raw 的雷达发射功率：Pᵣq；目标雷达功率：PᵣNᵣq²
B 的雷达发射功率：Pᵣ；目标雷达功率：PᵣNᵣq

只在“固定雷达子阵、单目标、精确单用户信道、正半定协方差、总雷达功率 Pᵣ、严格零干扰”这个子问题里，B 达到目标照射上界：Rᵣ 的支撑位于 ker(hᵣᴴ)，故 aᵣᴴRᵣaᵣ≤Pᵣ‖Πaᵣ‖²=PᵣNᵣq。q>0 时上述秩一权重达到等号。这不是整体分离/共享最优比较。

推广到 K 位用户时，零空间维数是 Nᵣ−rank(Hᵣ)，不是“每增加一位用户一定少一维”；相关信道不一定增加秩。即使维数大于零，额外每天线约束或指定方向图仍可能无解。本页程序仅计算 K=1。

数值零不能冒充物理结论

近重合时不用 1−|ρ|² 直接相减，而是用居中阵元和稳定的 exp(jx)−1 残差计算 q；先得到单位残差向量，再乘 √Pᵣ，避免 Pᵣ/q 溢出。近端射用端点余量求周期差，避免把两个不同方向误判为精确别名。

主目标读数使用上面的解析因子恒等式；完整记录另存同一权重直接复数求和的 *_direct 诊断。极深零点可能有双精度舍入残差，不能叫物理泄漏。正 q 进入次正规数或平方下溢时，程序明确报数值范围错误；它既不是精确重合，也不是子问题不可行，不用 epsilon 抬高 q。即使雷达预算为零，核心仍会计算该 q 诊断；这一极端输入也受相同数值范围限制。主界面固定 Pᵣ=0.5。

T 只问“发射端朝该方向有多少照射”。目标反射系数 β、接收阵列、传播损耗和接收噪声不在此指标内，不是把它们偷偷固定为 1；所以它不等于回波 SNR、CRB、检测概率、角度精度或空间分辨率。
