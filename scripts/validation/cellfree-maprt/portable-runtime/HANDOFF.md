# Frozen bounded runtime handoff

## Ready for integration

Nine dependency-free original ESM modules implement fresh scenario/moment estimation, source MAPRT, conditional finite-sample calibration/evaluation, and genuine bounded three-start CCP with convex-subproblem numerical gap gates. The selected candidate in each family is chosen by source sensing-SINR, before detector trials. Failed and nonselected starts are retained. RUNTIME-MANIFEST.json binds the executable files.

API, limits and scientific caveats are in README.md. Use the runtime archive for hosting, and the validation archive for regression evidence. Neither archive contains the source paper PDF, private paper code, or third-party numerical implementation. The original port code is included. Python source-reference oracle regeneration requires the separately accepted reference package; standalone NumPy MAPRT oracle does not.

## Gates and limits

Actual browser module-worker loading, CSP, cancellation responsiveness, UI and timing remain a website integration/deployment gate. Node Worker tests are not actual browser evidence. The cloud browser could not reach workspace localhost; the blocked navigation was not bypassed.

These are synthetic reduced conditional algorithms, not full-paper reproduction. Accepted CCP is local and numerical; certificates apply to convex tangent subproblems, not global nonconvex optimality. The native barrier Newton solver differs from source SciPy SLSQP and has its own retained failure statuses. Holdout feasibility, exact finite-sample Pfa control, simultaneous interval coverage, CFAR, and browser/device-wide memory guarantees are not claimed. Replay verifies detector-record consistency, not authenticity or independent optimizer certification.

The archived reference had nearly zero dedicated sensing power, unequal actual used power, holdout crossings and disagreement between surrogate and detection ordering. Fresh inputs need not reproduce those particular outcomes. Compare actual used expected power and retain W-symbol units unless a symbol duration is specified.

Portable validation archive was extracted into a clean temporary directory. All nine executable hashes verified, and runtime, adversarial contracts, power, client, Worker and standalone NumPy oracle checks passed from that extraction.
