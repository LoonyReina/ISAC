# 双路径主动无线链路：独立数值参考与接入合同

版本：1.0；日期：2026-10-11 UTC。用途：为「同一个终端，为什么收到两条路径？」提供可审查的独立数值依据。本文及同目录文件不修改教学网站，不代表已接入、已部署或已完成浏览器验收。

## 1. 结论与必须保留的边界

这里是单向主动链路：发射端 T→接收终端 P，或 T→墙面→P；每条路径的时延为 L/c，没有 2R。墙面反射是一条真实传播路径，不是另一个终端。匹配响应的局部/全局最大值不是目标检测，也不是二维位置。

模型已实际生成每个子载波的两个复数贡献及其和 Y。接收机只接收 Y、已知 X、频率 f 和固定候选网格，不接收 h、墙坐标、真实时延、路径系数、路径个数或分量标签。几何图、分量曲线和 Gram 诊断均为单独的生成器真值解释层。

保留：已知时钟参考、单天线、静态快照、平面一次镜面反射、未知复增益、完整固定频率网格、无噪声。省略：漫散射、噪声、Doppler、材料/极化、真实天线方向图、穿透和绕射、目标检测、路径关联算法、二维定位、CRB/EFIM、论文完整复现。

改变 h 同时改变两条路长、1/L 幅度和载波传播相位；这是一组不同静态快照，不是只改时延或固定相位的独立实验，更不是连续运动/Doppler 仿真。直接衰减 b 仅称为「理想直达路衰减干预」，不要凭空画一个未验证的遮挡物。

## 2. 相比候选提案的必要修正：整数频率与 CP

冻结采用 N=128，Δf=2 MHz，带符号整数子载波 k=-64,…,63，f_k=kΔf。参考载波 f_c=6 GHz，因此实际 RF 频点为 5.872…6.126 GHz，平均频率 5.999 GHz。254 MHz 是端点频率跨度，256 MHz 是 NΔf/DFT 名义带宽；二者都不是带外泄漏为零的硬件频谱占用承诺。

原候选的 k-63.5 半整数频率在 Tu=1/Δf 后改变符号：s(t+Tu)=-s(t)。普通「复制最后 32 个样点」CP 对它不成立，除非增加明确的符号修正/半频移解调约定。这里改用整数频率，s(t+Tu)=s(t)，直接复制 CP 与普通单位化 DFT 完全一致。不是 LTE/NR 波形声明。

该修正保持单路径 Dirichlet 核的模及两模板相关系数 χ；但在参考载波仍为 6 GHz 时，整组 RF 频点相对旧提案下移了 1 MHz，双路径相干功率不能宣称逐点不变。所有冻结场景统一使用修正后的频率和载波约定。

## 3. 几何、可见性与通道

单位均为米。T=(0,2)，P=(6,h)，h∈[0.1,6]，默认 h=4；墙为 y=0、x∈[-2,10]。镜像点 T′=(0,-2) 是计算工具，不是另一个电台。

Q=(12/(h+2),0)

L₀=√[36+(h−2)²]

L₁=√[36+(h+2)²]=|T−Q|+|Q−P|

τ₀=L₀/c，τ₁=L₁/c，c=299792458 m/s

Qx 在 1.5…5.714286 m 内，两端都在墙的同侧。T→Q、Q→P 两条开线段位于上半平面；场景假定无其他障碍。程序验证 Q 位于有限墙段，验证展开路长等于折线路长、入射角与反射角相等且 L₁>L₀；换成不含 Q 的有限墙段会拒绝场景。端点恰在 Q 的通用几何测试只按理想镜面处理，不模拟边缘绕射。

复系数定义为：

a₀=A b (Lref/L₀) exp(-j2πf_cτ₀)

a₁=A ρ exp(jψ) (Lref/L₁) exp(-j2πf_cτ₁)

其中 Lref=1 m，b,ρ∈[0,1]，默认 b=1、ρ=0.7、ψ=0。生成器的归一化约定固定 |A|=1，A=exp(jφA)，默认 φA=0.37 rad；这是一个未知于接收机的共同复因子，并非已标定的真实链路预算。ψ、φA 的有限输入域为 [-2π,2π]，已经覆盖所有不同相位。若将来允许 |A|>1，必须同时修改固定纵轴证明，不能沿用当前上界。

Y_k=X_k[a₀exp(-j2πf_kτ₀)+a₁exp(-j2πf_kτ₁)]

载波相位仅在 a₀、a₁ 中出现一次，f_k 仅为基带偏移。可等价直接使用 f_c+f_k 计算 RF 传播相位，测试已验证两种计算一致。未知复系数使接收机无法凭绝对载波相位恢复传播整圈或精确距离。1/L、频率平坦的反射系数是理想近似，不是材料测量或反射功率守恒的完整电磁模型。

## 4. 固定波形、CP 与资源账本

固定 QPSK 符号满足 |X_k|²=1/128、Σ|X_k|²=1。确定性算法：uint32 初态 0x5EED1234；每个频点先更新 state=(1664525·state+1013904223) mod 2³²；q=state>>30；取 [1,j,-1,-j][q]/√128。频点依次从 -64 到 63。无依赖语言运行时的随机库。

定义连续复包络（在完整发送区间内）

s(t)=(1/√Tu) Σ_k X_k exp(j2πk t/Tu)，t∈[-Tcp,Tu)

区间外此单个有限突发为零；CP 是周期包络在 [-Tcp,0) 的延拓。Tu=0.5 μs，Tcp=0.125 μs，完整发送持续 0.625 μs。接收机固定使用已知时钟参考的 [0,Tu) 窗口，不随 h 平移。全域最大绝对时延 10/c=33.35640952 ns 小于 125 ns，因此在整个接收窗口内，每个 t−τ 都落在有效的发送突发内。这个保证比只检查两条路的「超额时延」更强。

Fs=NΔf=256 MHz，Ts=3.90625 ns。归一化数字样点 q[n]=√Ts·s(nTs)=(1/√N)ΣX_kexp(j2πkn/N)。它们采用单位化 IDFT；逆变换也除以 √N。CP 对应复制最后 32 个 q[n]。

必须区分两种能量，不能把「CP 长度占 1/4」误写成「此固定波形的 CP 能量必为 1/4」：

- 连续有用区能量 ∫₀^Tu|s(t)|²dt=1
- 连续 CP 能量 ∫₋Tcp^0|s(t)|²dt=0.21922241148558474
- 连续完整突发能量=1.2192224114855845（二进制浮点舍入）
- 数字有用样点能量 Σ₀^127|q[n]|²≈1
- 数字 CP 样点能量 Σ₉₆^127|q[n]|²=0.21901243898695386
- 数字完整样点能量≈1.2190124389869537

部分区间的样点能量和连续积分不必相等。前者不是后者的精确替代。参考程序用有限 Fourier 级数交叉项解析积分计算连续 CP 能量，并用独立密集数值积分检验；数字账本用实际 IDFT 样点计算。所有场景 X 不变，两个账本分别保持常数，不对各场景重新归一化。归一化能量没有瓦特/焦耳或真实 RF 发射功率声明。

完整账本见 resource-ledger.json。所有对比保持 N、完整频点集、X、能量、时长、CP、接收窗口、单天线、候选网格和处理器相同。无噪声，噪声方差=0；接收能量自然随几何/衰减/干涉变化，绝不静默补偿成固定接收 SNR。

## 5. 接收机、解析核与固定纵轴

主接收机固定候选 d=0,0.01,…,14 m，共 1401 点。绝不把真实 L₀/L₁ 加入网格。d 是「候选总路径长度 cτ」，不是单站距离 cτ/2，也不是二维空间坐标。

z(d)=(1/E)Σ X_k*Y_k exp(j2πf_k d/c)，E=Σ|X_k|²

返回的是复数 z 和线性功率 |z|²。z(d) 可解释为每个候选下的单模板最小二乘复系数；这里没有联合估计两条路径的 a₀/a₁。归一化只使用已知的发射能量 E，不使用接收峰值、接收能量或真值。

独立解析校验令 q=Δf·u/c：

D(u)=(1/N)Σ exp(j2πkq)=exp(-jπq) sin(πNq)/[N sin(πq)]

z(d)=a₀D(d−L₀)+a₁D(d−L₁)

整数别名处用连续极限 D=1；实现先按整数周期规约 q，再使用 sinc 比值，不能省略 exp(-jπq) 的复相位。直接样点匹配与解析公式由不同计算路径比较。解析公式只供验证/生成器分量叠图，主接收机不调用它。

因为 |D|≤1、L₀≥6 m、L₁>6 m、|A|=1、b,ρ≤1，可得任意允许 h、ψ、b、ρ 和任意 d 下 |z|²≤(1/6+1/6)²=1/9。绘图纵轴统一固定 0…0.12，足以覆盖全域；不逐场景自动缩放或峰值归一化。

谱匹配的首零偏移是 1/(NΔf)=3.90625 ns，对应单向路径长度 1.1710642890625 m；延迟周期 1/Δf=500 ns、路径长度周期 c/Δf=149.896229 m。整数频点使复模板本身按此周期重复。旧的半整数频点则在一个周期后复模板翻符号、功率仍重复，未知复增益可吸收该符号。更细绘图网格只是在同一响应上更密采样，不增加带宽或独立信息。

单最大值读数只返回一个固定网格最大点，不估计路径/物体个数。精确相等的二进制浮点功率取最早索引，即最小 d；没有模糊的近似并列阈值。若所有功率恰为零，返回 status=no_response、estimate=null；不可显示「表观距离=0」。非零结果的 status=single_grid_maximum 也不代表通过统计检验的检测。先显示「候选总路径长度」；只有明确假设接收机把该最大值当直达路时，才称为「表观直达距离」。

## 6. 相干能量、重叠与严格奇异情况

总接收有用能量满足

Σ|Y_k|²/E=|a₀|²+|a₁|²+2Re[a₀a₁*D(L₁−L₀)]

响应曲线的功率同样有交叉项。两条独立功率曲线相加不等于收到两条复信号后再取模平方。fixtures.json 包含等幅近邻路的相长/相消场景，且接收机始终接收两路实际相加的 Y。

指定时延模板的单位化 Gram 矩阵 G=[1,g;g*,1]，其中按列 s₀、s₁ 的约定 G₀₁=Σs₀* s₁/N=D(-(L₁−L₀))，χ=|g|。特征值 1±χ，条件数 (1+χ)/(1−χ)。这只表示「在已给定两个时延时，分离两个未知复幅度的条件性」，不是时延 CRB、分辨概率、定位信息或算法成功率。

- 完全相同时延：只有 a₀+a₁ 可观测；若 a₁=-a₀ 则 Y 精确为零
- 完全整数周期别名：本整数频点网格产生相同复模板，也只能观测组合增益；这些低级代数夹具不属于本几何/CP 场景
- 近相同或近别名：仍是有限条件数，不用 epsilon 把它宣布成严格奇异
- near-zero q 使用稳定公式 1−χ=(2/N)Σ sin²[π(k−(N−1)/2)q]，避免计算 1−一个舍入为 1 的值
- 极小 q 导致浮点溢出/下溢时，condition=null、exactly_singular=false、numeric_status=binary64_range_limit，并保留有限 log_condition；严格奇异则 exactly_singular=true、numeric_status=exact_singularity。两个 null 不能混为一种结论

重叠≠所有位置相关信息都消失，单峰≠只有一条路径；参数可辨识、图上峰分离、数值稳定和噪声下可靠估计是不同问题。

## 8. API 与文件合同

reference.py 只依赖 Python 标准库，所有主 API 使用 SI 单位和 Python complex。JSON 中复数统一为 [实部,虚部]。

- Scene(h=4,b=1,rho=.7,psi=0,common_phase=.37)：有限域校验
- generate_scene(scene) → (receiver_input,generator_only)：前者只有 Y/X/f/candidates；后者才有场景、几何、系数、分量
- receive(Y=…,X=…,f=…,candidates=…) → z/power/estimate/status：冻结网格、固定 QPSK，不可给它真值
- geometry(h,wall)：返回路长、时延、Q、镜像点、角度与可见性检查
- matched_sum(...)：测试用任意候选列表的样点直接和；不是主界面可变网格
- dirichlet(u)、analytic_response(...)：独立解析校验与生成器解释层
- gram_at_delays(τ₀,τ₁)、gram_from_separation_cycles(q)：明确给定时延的 Gram 诊断
- synthesize_taps(...)：相同/别名时延的代数夹具，允许几何域外长度；不得包装成有效物理场景
- useful_samples()、interval_energy(...)、resource_ledger()：固定波形与资源账本
- scene_diagnostics(...)：生成器侧相干能量和 Gram；不要接进接收机

fixtures.json 提供 9 个物理场景、每场完整 128 个 Y、两路生成器贡献、部分固定候选处的复响应/功率、全网格最大值、几何和能量诊断；另含 3 个纯代数夹具、7 个 Gram 极限夹具、固定 X/f/候选网格。geometry/contributions 只可用于教学解释与数值验证，不能用于候选选择。

推荐移植对比：Y/z 绝对误差≤1e-12，普通功率≤1e-13；几何与能量按双精度约 1e-12；非常大条件数用相对误差，并同时比较 exactly_singular/numeric_status。精确并列最大值只在专用规则测试中比较；一般接近并列的极端场景允许不同平台的末位舍入使索引变化，不应把这种变化当成新路径。

运行：在本目录执行 python3 -m unittest -v test_reference.py；重新生成夹具执行 python3 generate_fixtures.py。实际运行的 29 个测试全部通过，测试输出见 TEST-RESULTS.txt。此测试不替代未来 JavaScript 移植后的独立对拍、完整仓库测试、页面结构/键盘/响应式验收或部署检查。

## 9. 选定论文的准确关系与证据

主要来源为 Leitinger 等《Evaluation of Position-related Information in Multipath Components for Indoor Positioning》，期刊为 IEEE JSAC 2015；固定阅读版本是 arXiv:1409.1467v2（2018-12-10 上传）。上传年份不是期刊发表年份。

- [§I/Figure 1](https://arxiv.org/html/1409.1467v2#S1)：平面图与镜像锚点，以及不同测量布置
- [§II/式(1)](https://arxiv.org/html/1409.1467v2#S2.EGx1)：复数延迟信号之和、距离/时延、单位能量发送信号
- [§III/§III-A/式(7)](https://arxiv.org/html/1409.1467v2#S3.SS1)：未知复幅度为干扰参数，接收数据进入似然
- [§IV/式(18)–(24)](https://arxiv.org/html/1409.1467v2#S4)：不同几何对应的时延关系
- [§V-A/式(36)–(38)](https://arxiv.org/html/1409.1467v2#S5.SS1)：非重叠/正交假设下的信息解释
- [§VI-B1/Figures 3–5](https://arxiv.org/html/1409.1467v2#S6.SS2.SSS1)：路径重叠的数值研究

本站参考保留几何、复数叠加和未知增益思想。N=128、2 MHz、6 GHz、QPSK/CP、1/L 简化幅度、固定匹配接收机和 Gram 条件数都是独立教学设计，不是论文参数或其 CRLB 结果。没有复制论文图、实验数据或完整算法。文献全文不在此交付目录中。

已知墙面/地图、路径关联和时钟同步是额外条件。绘图时看到墙不等于接收机知道墙；一条标量时延不能给出二维点。直达路被衰减到零时，最早可见路径可以是反射路，不能把它重命名为 LOS。后续若引入未知时钟、未知地图、角度、多锚点或定位算法，必须显式扩展观测与先验资源，不能借当前单天线双路径匹配曲线宣称多径普遍有益。
