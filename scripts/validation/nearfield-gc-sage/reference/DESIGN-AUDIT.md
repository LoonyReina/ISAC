# Near-field GC-SAGE: technical audit and implementation specification

Source fixed for this audit: Yuan Liu et al., arXiv:2605.01162v1, submitted 1 May 2026. [PDF](https://arxiv.org/pdf/2605.01162v1), [HTML](https://arxiv.org/html/2605.01162v1), [version record](https://arxiv.org/abs/2605.01162v1). Checked 12 October 2026. This is a specification and mathematical audit, not a claim that the estimator or the paper's experiments have been reproduced.

## Implementation correction (version 0.2.0)

The implemented conservative contract now requires all channel-dependent bounce points to lie in V within 1e-10 m, including channels with near-zero fitted gains. Eqs. 19 and 21 explicitly restrict their point sets to V, and Eq. 23 intersects them. An exemption for invisible channels is not explicit in the source. The earlier reference-point-only model and results are superseded; see VERIFICATION.md for the regression and revalidation.

## 1. Decision and claim boundary

The next useful teaching implementation is a **two-path, one-bounce, wideband inverse problem**. One hidden path is generated by a fixed scatterer and one by a finite planar reflector. Both estimators receive the same noisy frequency-domain data. The scattering-only estimator and the hybrid estimator must both fit a complex gain independently for each Tx/Rx channel. The hybrid changes the geometry candidates in the M-step; it does not receive the mechanism labels, locations, surface normal, visibility mask, or true delays.

A restricted estimator with these properties is a faithful implementation of the paper's one-bounce mechanism-comparison core. It is not a reproduction of the complete GC-SAGE algorithm, which additionally discusses bounce-order decisions, two-bounce searches, and high-bounce delay-only updates. It is not a reproduction of Figures 5–9, whose raw channel data and complete generation/optimization settings have not been obtained.

Do not promote the existing known-geometry point-versus-plane forward helper to an estimation result. Keep it as a geometry prerequisite. The new core must reconstruct unknown parameters from samples and display its actual optimization trace.

### What the comparator actually is

The paper's scattering-only baseline already includes partial blockage and channel-wise amplitude variation. A comparison against a single constant gain over the whole array tests two differences at once and cannot isolate the added reflection constraint. A stationary-gain ablation can be offered separately, clearly named as an additional pedagogical baseline.

## 3. Mathematical kernel, independently derived for implementation

Use q=(m,n) to index Tx/Rx pairs and p=0,...,P−1 to index tones. All positions below are in meters. Let c=299792458 m/s. Work in a 2-D slice with known transceiver positions t_m and r_n.

Observation model:

    Y[q,p] = sum_l A[q,l] exp(-i 2 pi nu[p] d[q,l]/c) + W[q,p]

Here A is one unknown complex number per path and Tx/Rx pair. It absorbs the stationary path gain, visibility, attenuation, and a per-channel frequency-independent phase. For simulation only, build A[q,l] from a truth-only visibility mask and optional amplitude taper. Do not pass its decomposition to the estimator.

Use centered frequencies nu[p]=(p−(P−1)/2) B/(P−1). This is equivalent, under unconstrained complex A[q,l], to using carrier-plus-offset frequencies: the constant factor exp(-i 2 pi fc d/c) can be absorbed into A. Consequently:

- A single-tone version has no geometry information after one free complex gain is fitted per channel
- Shifting the frequency origin in the steering model for the same observed Y leaves its profiled losses unchanged; do not claim a wavelength-based localization gain from carrier alone under this free-gain model
- Carrier remains relevant when converting wavelength-based array spacing to physical aperture or adding separately justified frequency-dependent physics
- Do not silently switch to a globally phase-coherent scalar gain to make the estimator look sharper

Changing the physical carrier while regenerating multiple paths with fixed generator gains can also change their relative interference phases. That is a different experiment from shifting the frequency origin of the same observation. It still does not restore an across-array carrier-phase constraint that free per-channel gains have removed.

### 3.1 E-step / hidden data

For the path currently being updated:

    R_l = Y − sum_(k != l) Zhat_k
        = Zhat_l + (Y − sum_k Zhat_k)

This is the active-path noise allocation choice beta=1, using a fresh allocation for each sequential SAGE subproblem. Use the newest accepted estimates of other paths. This is a standard sequential SAGE/coordinate convention; the paper does not specify numerical beta choices or a detailed update schedule. Do not pretend those missing numerical choices came from its implementation.

### 3.2 Profile out the gain for every candidate

For any candidate geometry g, construct s_q(g)[p]=exp(-i 2 pi nu[p] tau_q(g)).

    Ahat[q,l | g] = (s_q(g)^H R_l[q,:]) / P
    J_l(g) = sum_q ( ||R_l[q,:]||^2 − |s_q(g)^H R_l[q,:]|^2 / P )

This is the unambiguous scalar least-squares form of the equivalent-gain operation. It avoids treating the paper's path signal z_l as both a fitted signal and a unit-amplitude design matrix. A non-unit steering vector would require its actual squared norm in the denominator.

Roundoff can make the subtractive objective slightly negative when the true residual is zero. Use the subtractive expression to rank candidates, then compute the final accepted residual directly. A tiny negative value may be clamped only within a stated roundoff tolerance.

### 3.3 Reference delay estimation must use data

Known model order is allowed as an explicit first-release assumption: L_fit=2. Estimate two reference delays from the selected observed channel, not from the generator. Suggested transparent initializer:

1. Search a bounded delay grid by matched-filter magnitude
2. Fit the winning complex gain and subtract that component
3. Repeat for the requested number of paths
4. Run two or more single-channel SAGE refinement sweeps, alternately refitting each delay and gain against the residual of the other paths

This greedy-plus-SAGE initializer is a disclosed numerical choice. The source only specifies conventional SAGE initialization, without enough detail to reproduce its exact initializer. Avoid marking two adjacent samples of the same peak as separate paths: use local maximization / exclusion around the selected lobe and then refine continuously or on a finer local grid. The exclusion width is a numerical heuristic, not a guarantee of resolvability.

For the strict first implementation, hold each estimated reference delay fixed while fitting spatial geometry. The ellipse constraint then has a clear meaning. Optional local refinement of the reference delay inside every spatial M-step is a useful extension but must be labeled as such and given the same budget in both estimators.

### 3.4 Ellipse candidates

Given reference endpoints t_0 and r_0 and estimated reference length D_l=c tauhat_ref,l:

    center = (t_0+r_0)/2
    focalHalfDistance = ||r_0−t_0||/2
    a = D_l/2
    b = sqrt(a^2−focalHalfDistance^2)
    e1 = (r_0−t_0)/||r_0−t_0||
    e2 = (-e1_y,e1_x)
    s(theta) = center + a cos(theta)e1 + b sin(theta)e2

Reject D_l < ||r_0−t_0||; do not repair such an estimate using true delays. Treat the equality/degenerate ellipse separately as a possible LoS component rather than an ordinary reflector. Filter candidate points to the declared search region V. For a monostatic reference use a circle and a separately chosen orientation basis.

Scattering candidate s has:

    d_sc[q] = ||t_m−s|| + ||r_n−s||

The same s is used at every channel. Its gains still vary freely across q.

### 3.5 Reflection candidates from the same ellipse

For each s on the reference ellipse:

    v = (s−t_0)/||s−t_0|| + (s−r_0)/||s−r_0||
    u = v/||v||
    plane/line: u dot (x−s) = 0
    t'_m = t_m − 2u [u dot (t_m−s)]
    h = u dot (r_n−t'_m)
    t = [u dot (s−t'_m)] / h
    b_q = t'_m + t (r_n−t'_m)
    d_rf[q] = ||t_m−b_q|| + ||r_n−b_q||

Reject zero-length vectors, ||v|| near zero, grazing intersections |h| near zero, and nonphysical ray intersections. For a reflection between two terminals on the same side of the surface, require 0<t<1, and verify the two-leg distance agrees with ||t'_m−r_n||. Check reference consistency d_rf[ref]≈D_l.

The unknown reflector is a shared line (a plane in the full 3-D model); its individual b_q points move across the aperture. Do not constrain every b_q to the reference ellipse. Do not fit a separate arbitrary line to each channel.

The candidate line need not know the true finite segment endpoints. Estimate support from the fitted gains and plot only bounce points supported by detected power. Finite truth segment endpoints enter the forward generator only.

### 3.6 Mechanism selection and monotonicity

For each path, find the best scattering candidate J_s and, in the hybrid, the best reflection candidate J_r. Keep the previous accepted path state as a candidate. Accept a reflection only when it improves on the scattering result and does not increase the previous global squared residual. Otherwise use an improving scattering state or retain the old state.

Use one consistently defined global objective:

    SSE = ||Y − sum_l Zhat_l||_F^2
    relativeResidual_dB = 10 log10( SSE / ||Y||_F^2 )

The source writes an unsquared norm in Eq. 13 and squared norms in its M-steps; both have the same minimizer. Name the plotted definition explicitly rather than implying exact agreement with the dB scale of Figure 9.

Comparing the two candidate families with the same per-channel gain count and the same ellipse resolution avoids an obvious parameter-count imbalance. A lower training residual by itself does not prove correct mapping. Always include geometry error or an independent predictive check in validation.

### 3.7 Visibility is inferred, not revealed

Plot |Ahat[q,l]| or |Ahat[q,l]|^2 over the array before thresholding. An optional displayed visibility decision can use:

    visible_hat[q,l] = ( |Ahat[q,l]|^2 > −log(p_false) sigma^2 / P )

For an isolated known-delay path and circular Gaussian noise this follows from the exponential distribution of the squared matched-filter noise gain. Geometry selection, multiple testing, multipath leakage, and fitted parameters invalidate an exact global false-alarm interpretation. Label it as a display threshold heuristic, not the paper's specified detector. A default p_false=0.01 is an implementation choice. The paper does not provide a unique binary support threshold.

Do not replace the estimated gains with the true visibility window, and do not hard-threshold inside the optimizer without documenting an added regularizer. Gamma and attenuation are not separately identifiable from their product without extra assumptions.

If the chosen reference channel cannot see a path, reference-only initialization can miss it. State this limitation. A multireference candidate union is a possible later extension, not a truth-assisted fix. Defaults should choose a reference inside both paths' visible support.

The default reflector produces specular points with x=(1+x_Rx)/2. Its finite x=[1.5,2] support therefore illuminates approximately x_Rx=[2,3], while the rest of the aperture sees zero reflection gain. This is a physical finite-segment support example, not an arbitrary mask fed to the estimator. A separate blockage control can remove an interval of receivers in the generator.

At the aperture midpoint x≈2.745734, the reference is visible to both paths. The rough path and reflected path have separated delays (about 10 ns and 14.6 ns), allowing a reasonable first teaching case. These numbers are geometric expectations, not estimator test results.

**Important downsampling disclosure:** 200 receivers at 0.75 lambda and 30 GHz span approximately 1.4915 m. Forty-eight uniformly spread virtual samples preserve that aperture but are not a 0.75-lambda dense array. Say “48 virtual samples across 1.49 m.” Keeping 0.75-lambda spacing while dropping to 48 would shrink the aperture to about 0.352 m and change the experiment materially.

### Noise and budget definitions

Generate W[q,p] independently as sqrt(sigma2/2)(G1+iG2) with seeded standard normal G1,G2. Define sigma2 from the clean unblocked reference scene's mean per-sample power and the nominal SNR control. Keep sigma2 fixed as blockage/visibility changes, so blocking a path actually loses received energy. Show both nominal SNR and realized received SNR for the current scene. A current-scene-normalized SNR mode may be added, explicitly described as compensating for lost signal power.

Both algorithms use precisely the same Y, frequencies, coordinate samples, reference initializer output, known L, search region, stopping tolerance, and noise seed. Give the hybrid its required additional reflection search and show the added operations/runtime; do not pretend it costs the same. For a fixed-time comparison, separately declare the unequal candidate allocation instead of silently starving one baseline.

MIMO mode uses more observations if per-channel energy is held fixed. Do not attribute all improvement to geometry while hiding this budget increase.

### Aliasing and controls

Uniform tone spacing has delay period 1/Delta_f. P=64 and B=1 GHz give 63 ns. Search delay must remain below that period and accommodate the scene. Changing B or P requires recomputing this bound; disable or flag ambiguous controls rather than wrapping to a plausible location. The P=32, B=2 GHz setting has only 15.5 ns unambiguous delay and cannot support a generic 55 ns search without alias handling.

### Interaction and compute design

Run fitting in a Web Worker. Debounce scene edits, retain a deterministic seed until explicitly changed, and expose cancellation so a stale solve cannot overwrite a newer scene. Never update the displayed fit by moving truth geometry directly.

The direct one-bounce cost is proportional to I L Q M N P per candidate family, not merely the geometry-only asymptotic count. For I=8, L=2, Q=256, M=1, N=48, P=64, the baseline plus hybrid is approximately 37.7 million candidate-tone projections before refinement. This is a workload estimate, not a latency measurement.

Cache candidate delays and steering dictionaries when possible. Frequencies are uniform, so a phase recurrence can replace per-tone transcendental calls. A fully cached 2-path, 2-family, 256-candidate, 48×64 complex Float32 dictionary is about 24 MiB before refinement. Cache per path or only delays to bound memory; 3-Tx mode triples this footprint. Benchmark real browsers before claiming real-time latency.

Show states “simulating,” “fitting,” “converged,” “iteration budget reached,” and “initialization failed” truthfully. Reaching a sweep cap is not convergence.

## 5. Teaching outputs and validation

Show four linked panels:

1. True scene plus estimated point(s), line(s), and only data-supported bounce points
2. Observed delay-aperture magnitude map from the same Y, with true and estimated delay tracks separately toggleable
3. Estimated channel-wise amplitudes, with truth mask available only as an evaluation overlay
4. Actual residual objective versus accepted path updates / sweeps, and measured runtime for each estimator

For a selected path, expose the ellipse, candidate sweep, current scattering/reflection losses, mechanism decision, fitted gain profile, and the residual before/after updating that path. A play/step control should execute actual updates, not reveal a prewritten story.

Metrics:

- Training relative residual as defined above
- Clean-channel NMSE = ||Hhat−Htruth||²/||Htruth||², simulation-only
- Scatterer Euclidean error after an explicitly documented matching rule
- Reflector normal-angle error modulo sign, and signed-distance/offset error using a consistent normal orientation
- True versus estimated visible support, with threshold policy stated
- Covered reflector extent, not a claim to recover unilluminated physical endpoints
- Mechanism label accuracy only after path association, with low-confidence / near-tie outcomes retained

Optional independent check: fit geometry and gains using an interleaved 75% subset of frequencies and predict the held-out frequencies with the same fitted gains. Do not use held-out antennas to test this free-per-antenna-gain model unless an additional gain interpolation prior is introduced. Held-out-tone validation is an added validation tool, not a result reported in the paper.

### Required automated tests before a “core implemented” label

- Truth isolation: estimator input excludes all truth geometry, mechanism labels, masks, and delays
- Determinism: same configuration and seed produce same observations and fit
- Same-data comparator: both algorithms consume identical complex Y
- LS fixture: isolated known geometry exactly recovers the complex per-channel gains in noiseless data
- SAGE fixture: adding back the active estimate to the total residual equals subtracting all other paths
- Scattering geometry: one shared interaction coordinate and correct total path length
- Reflection geometry: unit normal, correct mirror, equal angles, channel-dependent bounce coordinates, path length equality, reference ellipse consistency
- Window fixture: a finite segment limits simulated support but no support is supplied to fitting
- Objective: every accepted update is nonincreasing within numerical tolerance; use explicit residual recomputation to verify
- Single-tone identifiability: profiled loss is flat over valid geometries in the isolated-path single-tone case
- Carrier-offset invariance: profiled losses agree for centered and carrier-shifted tone frequencies, up to numerical tolerance
- Array-aperture regression: changing sample count at fixed aperture does not silently change endpoint coordinates
- Noise/seed: observed metrics and fit change when seed or noise changes; UI does not replay canned values
- Degeneracies: invalid delay ellipse, zero normal, grazing line, entirely invisible path, two unresolved reference peaks, and delayed worker cancellation handled explicitly
- No false robustness claim: at low SNR, narrow bandwidth, or small visible aperture, retain mechanism errors/uncertainty rather than forcing the expected label

Do not hard-code “hybrid always wins.” Nested candidate searches may ensure an in-sample fit advantage under sufficiently comparable optimization, but geometry and out-of-sample performance can degrade with noise, initialization, or model mismatch.

## 7. Apparent formula ambiguities and geometric consistency checks

These are implementation cautions, not a blanket assertion that the paper's intended method is wrong. An omitted convention, typographical error, or implicit operation may explain them. PDF pages 6–7 were visually inspected as well as text-extracted.

### A. Normal normalization: Eqs. 9 and 20, pp. 5 and 7

Eq. 9 defines the normal direction as a sum of two unit vectors; Eq. 20 uses the mirror term −2 n n^T(t−s). No explicit unit-normal normalization was located in the surrounding definitions. The mirror expression is correct if n is implicitly normalized. A scale-invariant implementation is −2 n[n^T(t−s)]/(n^T n), or explicitly u=n/||n|| first.

Independent check: t=(0,0), r=(2,0), s=(1,1). Eq. 9 yields n=(0,sqrt(2)); the reflecting line is y=1. The physical Tx image is (0,2). Direct substitution of the unnormalized n into Eq. 20 instead yields (0,4). Normalizing produces the correct image and equal incidence/reflection angles.

### B. Two-bounce residual length: Eq. 17, p. 6

The printed final subtraction is −||r_Rx,n0−r1||. The surrounding prose calls r1 the first scatterer on Tx→r1→r2→Rx, and Eq. 5 includes the Tx-to-first leg. The residual length available for r1→r2→Rx must therefore be D−||t_ref−r1||. This could be a Tx/Rx subscript typo. If a different ordering is intended, both the ordering and all associated terms must be changed consistently.

Independent check: t=(0,0), r=(4,0), r1=(1,1), r2=(3,2). Total D=5.8863495174 m. The last two legs total 4.4721359550 m. Subtracting the Tx-first leg gives exactly that value; subtracting the Rx-first distance gives 2.7240718572 m.

### C. Line parameterization: Eq. 21, p. 7

Eq. 21 equates (x−t')/||x−t'|| and (x−r)/||x−r||. It correctly indicates collinearity only on the exterior portions of the line; between t' and r those vectors point in opposite directions. The text intends the straight line through the mirrored Tx and Rx. Implement x=t'+t(r−t') and intersect it with the plane, with the physical-segment check 0<t<1.

Independent check using case A: t'=(0,2), r=(2,0), physical bounce s=(1,1). The two normalized vectors at s are (1,−1)/sqrt(2) and (−1,1)/sqrt(2), opposite rather than equal. The parametric-line formula gives t=1/2 and the correct bounce.

### D. Noise-allocation and amplitude notation

Eq. 11 writes a noise allocation with sum beta_l²=1, while Eq. 14's M-step denominator uses beta_l sigma0². An implementation should explicitly define its latent-noise covariance convention rather than silently mixing the two. The active-path beta=1 sequential formulation avoids a consequential scale ambiguity in each subproblem. Since that denominator is constant over geometry candidates, its positive value does not affect a single path's candidate argmin.

Eq. 18 is written using the path signal z_l in the least-squares design expression. The kernel above uses a clearly defined unit-amplitude steering vector and fits the equivalent complex gain. This is a dimensional/linear-model clarification, not an extra estimator.

## 8. Reference fixtures supplied with this audit

The companion JSON contains exact small geometry and noiseless signal fixtures, including a partial-visibility example. It is suitable for independently testing a future implementation. It is not an implementation of GC-SAGE or an experimental result. Float64 checks should use tolerances around 1e−10 for the small geometry/gain fixtures and relaxed, explicitly documented tolerances for Float32/browser kernels.

Suggested implementation order: geometry + gain fixtures; seeded observations; reference SAGE initialization; scattering-only spatial SAGE; reflection M-step comparison; live visualization; repeated-seed validation; four-path Figure-5-inspired preset; only then two-bounce and measurement milestones.
