一条主线，而非一张名词清单

先让环境在信号上“留下指纹”

① 发射选择波形 s、波束 w② 传播距离 → 延迟；运动 → 相位变化③ 处理相关、变换、参数估计④ 决策峰值够不够可信？⑤ 反馈跟踪结果指导下一次发射

感知不是恢复“发了哪个比特”，而是借助已知信号恢复传播参数。先忽略杂波与硬件误差，单目标的复基带模型是：

y(t) = a · s(t − τ) · exp(j2πfDt) + n(t)

a：复幅度；τ：传播延迟；fD：频移；n：噪声。阵列加入方向响应，多目标则对各条路径求和。单站下 τ ≈ 2R/c；双站下测到的是发射机—目标—接收机的总路径。窄带、低速近似下，传播的时间缩放可简化为多普勒相位项。模型基础见 [2] §II。

实验 01 · 从你已经推出来的公式出发

多普勒：变的不是发射节奏，而是到达节奏

每个圆只记住发出那一刻的位置，不会跟着波源一起移动。观察接收点被波峰扫过的间隔。

正值：靠近；负值：远离。左图是经典声波归一化模型，不是以巨大速度运动的电磁波。

波源运动时，前方波峰间隔变短、后方变长。

教学单位：cs = 130 长度单位/s，fb = 2 Hz。相同时间轴与波速；无介质流动、无超声速运动。图中的发射范围在循环末端重置。

先预测：相隔 Tb 发出的两圈波，第二圈少走 vTb。到达间隔少了多少？
展开推导：到达时刻相减，比背公式更直接

设第一圈发出时源到接收点距离为 D。在静止介质参考系中，第一圈 t1 = D/cs 到达；第二圈 t2 = Tb + (D − vTb)/cs 到达。因此：

Tr = t2 − t1 = Tb(1 − v/cs)
fr = fb / (1 − v/cs)

这里接收机相对介质静止，v 是沿连线的源速度，|v| < cs。不要把这个精确声学公式原样当成真空光波的精确公式；光源固有频率对应的纵向相对论因子是 √[(1+v/c)/(1−v/c)]。低速时两者的一阶近似相同。基础对照：OpenStax。

接到 ISAC：为什么单站是 2，双站却不一定？

电磁波的更通用低速直觉是“总路径每秒改变多少个波长”。令 L(t) 为传播路径长度，λ = c/fc，传播相位 φ ≈ −2πL/λ：

fD ≈ (1/2π) dφ/dt = −(1/λ) dL/dt
单站：L = 2R → fD ≈ −2Ṙ/λ

以接近速度 vr = −Ṙ 为正，就有 fD ≈ 2vr/λ。5 GHz 时 λ ≈ 0.06 m，径向接近 1 m/s 对应约 +33.33 Hz。

双站中 L = |p−pT| + |p−pR|。发射机与接收机固定，令 uT、uR 分别由两站指向目标，目标速度为 v，则 fD ≈ −v·(uT+uR)/λ。两段路径可能一长一短，部分甚至完全抵消。WiFi 反射链路不能一律套 2v/λ。这些是低速、窄带的一阶关系，见 [1]、[2] 的信号模型。

实验 02 · 从延迟到“对齐”

匹配滤波：拿已知波形当尺子，沿回波滑过去

蓝线是收到的回波，橙色虚线是平移后的参考模板。把对应样本相乘再相加，看看哪一个平移位置得分最高。

匹配滤波通过扫描模板的延迟寻找相关峰。

离散实基带模型；真实延迟 25，弱目标为 33，弱目标幅度 0.45。两种发射序列长度与能量相同（13），但频谱不同，不是固定带宽下的公平优劣结论。曲线是实际离散相关计算，不是手绘峰形。

试一下：先选相位码，再勾选“保留旧模板”。处理仍然是“滑动、相乘、累加”，为什么峰变了？
展开推导：同一种算法，为什么需要不同系数？
z[ℓ] = (1/13) Σj=0…12 y[j+ℓ] s*[j]

若 y[n] = a s[n−d] + n[n]，那么 z[ℓ] 的有用部分就是波形自相关在 ℓ−d 处的取值。对齐时，同一波形的能量相加；错开时，正负项可能抵消。复基带要取共轭，这里的 ±1 实序列共轭后不变。

换了波形，相关这一算法框架可以不变，但参考 s 要更新。“接收算法没有创新”与“接收端一行配置都不改”是两回事。在白高斯噪声、已知确定信号等条件下，匹配滤波有输出信噪比最优性；有色干扰可能需要白化或失配滤波。

此处没有载波多普勒；有频移时还可扫描频率补偿，得到二维的延迟–多普勒匹配。进一步研究：主瓣宽度、旁瓣、模糊函数、恒模约束。阅读 [2] §II.C、§III、§V。

实验 03 · 把相位变化变成坐标

OFDM：距离藏在频率轴，速度藏在时间轴

左图的颜色代表复数相位，不是功率。右图通过子载波方向 IFFT + 慢时间方向 FFT计算得到。先只调距离，再只调速度。

取消消除数据：不是目标消失，而是随机通信相位把规律盖住。非整栅格参数会使能量泄漏到邻近栅格。

距离对应跨子载波相位斜率，速度对应跨探测时刻相位斜率。

32 子载波 × 32 次探测；Δf = 1 MHz，fc = 5 GHz，CP = 1 μs，探测间隔 Tr = 1 ms（含间歇，并非 1 μs 的 OFDM 有效符号时长）。同步、单目标、恒速、无距离迁移近似；每个 I/Q 噪声分量标准差 0.08；右图按当前最大值归一化，显示 −40 至 0 dB。

先预测：目标静止时，沿时间方向的相位还会持续转动吗？把距离改为半个栅格，峰为什么不再只在一个点上？
展开推导：为什么除掉数据之后就可以做二维 FFT？
Y[k,m] ≈ a X[k,m] exp(−j2πkΔfτ) exp(j2πfDmTr) + N[k,m]
Ĥ[k,m] = Y[k,m] / X[k,m]

去掉数据后的频率轴相位步进为 −2πΔfτ；时间轴相位步进为 +2πfDTr。傅里叶变换会把“固定步进的旋转”聚成峰。单站再用 R = cτ/2、vr = λfD/2 变成距离和速度。

ΔR ≈ c/(2NΔf) = 4.6875 m
Δv ≈ λ/(2MTr) = 0.9375 m/s

这些是本教学矩形窗的栅格间隔和标称分辨尺度，不是单目标估计误差。补零可以加密显示栅格，却没有增加观测信息。CP 大于往返延迟、符号内频移较小、定时与频偏已校准，是此简化模型的重要条件。

QPSK 在这里等模且全部已知。若改成幅度变化的 QAM，除以小幅度符号会放大噪声；若子载波为零，就不能直接相除。缺失或非均匀采样也会改变旁瓣与模糊性，可能需要加权、插值、非均匀变换或其他估计方法。这里展示的是 OFDM 解调后的感知模型，不是完整射频收发仿真。原文定位：[1] §IV.B.2，式 (46)–(52)，图 10。

实验 04 · 有峰，不代表有目标

CFAR：让门槛跟着背景走，而不是跟着感觉走

Constant False Alarm Rate，恒虚警率检测。它回答“这个单元显著高于局部背景吗”，不是负责生成距离–多普勒图，也不是滤掉噪声。

CA-CFAR 用邻近训练单元估计背景，跳过保护单元和待测单元。

柱：线性功率；实线：CA-CFAR 门限；虚线：按 μ=1 标定的固定门限。窗内标记 T/G/CUT 分别为训练/保护/待测。边缘不满足完整训练窗的单元不检测。目标是加到复高斯噪声上的确定幅度、局部扩展回波；随机种子可重现。

操作顺序：先切“只有噪声”，把 μ 从 1 拉到 4，观察固定门限；再回到目标，切“近邻强目标”，看训练窗如何被抬高。
展开推导：CA-CFAR 的门槛究竟怎么计算？

CUT 是当前待测格；保护格不参与平均，以减少目标主瓣泄漏；训练格用来估计背景。“训练”在这里是取局部参考样本，不是训练神经网络。

μ̂ = (1/N) Σi∈训练窗 P[i]
T = α μ̂；若 P[CUT] > T 则报警
α = N (PFA−1/N − 1)

该 α 对应：无目标时，CUT 和 N 个训练功率样本独立同分布、为相同均值 μ 的指数随机变量；这可来自圆对称复高斯噪声的模平方，且没有非相干多脉冲积累。N 是两侧训练格的总数。平均应在线性功率域做，不能把 dB 数直接平均后套此公式。

更进一步：给定 μ̂，虚警概率为 exp(−αμ̂/μ)。对训练样本平均后，PFA = (1+α/N)−N；反解就得到上式。背景整体放大时，CUT 与门槛一起同比放大，判决不会因为这一共同尺度而改变。出处与条件：[CFAR]。

若一张图有 M 个纯噪声待测格，每格 PFA = p，则虚警数期望为 Mp；独立时至少一次虚警的概率为 1−(1−p)M。有相关时，期望关系仍成立，但后一个公式通常不能直接用。

为什么背景台阶或近邻强目标会使它失灵？

台阶破坏局部同分布假设；其他目标进入训练窗会抬高估计背景，弱目标可能被遮蔽；相关样本、重尾杂波和加窗后的统计变化也会使名义 PFA 不再准确。保护窗只隔离附近泄漏，不能保证排除所有目标。

GO-CFAR 取两侧均值中较大者、SO-CFAR 取较小者、OS-CFAR 使用有序统计量，各有场景取舍，门限系数也需要按各自模型校准。不能把 CA 的 α 原封不动用于 OS。本页实际实现的是 CA-CFAR，不是这些扩展算法。参见 [CFAR]；真实干扰类型再读 [5]。

实验 05 · 把时间上的对齐搬到空间

波束成形：不是把天线转过去，而是把相位对齐

波从不同方向到达，各阵元的路径差不同。补偿相位后，同向的复数箭头能相加；没对齐时，它们会相互抵消。

固定目标 +25°，通信用户 −25°。左图展示目标方向信号经相位补偿后的箭头；共同旋转不改变相干增益。

调整指向时，目标方向的相位对齐程度与阵列增益变化。

均匀线阵，d = λ/2，远场、窄带、理想阵元，无互耦。角度相对阵列法线。方向图按 N² 归一，主峰 0 dB；不代表总功率、链路预算或最终定位误差。

先预测：N 增大后，主瓣更窄。在方向预测有误时，这一定是好事吗？
展开推导：路径差 → 相位差 → 空间匹配
相邻阵元路径差：d sin θ
补偿后的相位步进：ψ = (2πd/λ)(sin θ − sin θ₀)
G(θ;θ₀) = |Σn=0…N−1 exp(jnψ)|² / N²

当 θ=θ₀，每一根箭头同向，归一化增益为 1。偏离时逐步相消。接收波束是对来自某方向的信号做相干合并；发射波束则控制不同方向的辐射。理想互易阵列可出现相同的阵列因子，但发射权重与接收权重是不同设计变量。

因此，波束成形既可属于发射设计，也可属于回波处理；前一版的栏目只是研究切入点，不是互不耦合的硬件模块。对于固定总发射功率，理想峰值阵列增益随 N 变化；本图的逐 N 峰值归一化没有画出这部分绝对增益。
