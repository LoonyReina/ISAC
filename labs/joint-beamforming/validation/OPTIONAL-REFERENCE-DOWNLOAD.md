# Optional complete numerical reference

The complete frozen reference archive is delivered as three ordered binary parts to fit the publication transport limit. Download all three parts, `joint-beamforming-reference-v1.parts.json`, and `reassemble-reference.py` into the same folder. Then run `python reassemble-reference.py`. No extra Python package or network access is required.

1. `joint-beamforming-reference-v1.zip.part01`
2. `joint-beamforming-reference-v1.zip.part02`
3. `joint-beamforming-reference-v1.zip.part03`

The script checks every part before reconstructing `joint-beamforming-reference-v1.zip`, then verifies its25,845,796-byte size and SHA256 `3baff9d3e29cec528442fc2c4b9ab8dc34aceb7076803ca4e0c1f6783b4a59b2`. It does not overwrite an existing different archive. These are raw chunks of the original frozen ZIP, not new compressed scientific evidence.

Extract the verified ZIP to inspect every historical result, matrix, factor and certificate. The readable selected evidence remains the smaller primary download. These optional parts are never fetched by the interactive lesson at startup.
