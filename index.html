01 / 核心直觉

通信恢复消息，感知估计环境

同一段电波到达接收端时，既携带人为编码的数据，也留下传播环境的痕迹：传播延迟、频率偏移、不同天线上的相位差。

COMMUNICATION

“发送了什么？”

终端解调符号、译码比特。信道的影响通常需要估计与补偿。

关注：速率、误码率、可靠性、时延。

SENSING

“周围有什么？”

用已知或可重构的信号，估计目标是否存在，以及距离、速度、角度。

关注：检测概率、虚警概率、估计误差、分辨率。

INTEGRATION

“怎样一起做好？”

共享频谱、硬件、波形或网络资源；也可用感知结果帮助波束跟踪，用通信网络融合多站观测。

共享带来效率，也带来资源与性能约束。

ISAC 的“感知”主要指利用无线传播感知环境。把摄像头拍到的视频通过 5G 上传，本身并不等于射频通感一体。

概念与分类参考 Fan Liu 等的全景综述 [1]。本站图均为教学重绘，非论文实验结果。

02 / 起源与发展

不是从 6G 才出现的想法

通信与雷达长期共享电磁波、阵列和信号处理基础。今天的变化，是把融合从单台设备推进到大规模无线网络。下面是理解脉络的阶段划分，阶段之间存在重叠。

1960s · 在雷达脉冲里传信息

早期方案通过雷达脉冲间隔等参数承载消息，是双功能思路的先例，而非现代蜂窝 ISAC 的完整形态。[1]

1990s–2000s · 多功能射频与共享硬件

雷达、通信等功能逐步寻求共用天线与射频前端；阵列、MIMO 等技术成为交汇基础。[1]

2010s · 从频谱共存走向联合设计

问题从“如何少互相干扰”扩展到“如何让一次发射同时服务两种任务”；OFDM 与多天线方法成为重要技术路线。[2]

2021–2022 · 系统化的 ISAC 研究框架

多篇综述梳理应用、收发信号处理和性能边界。研究对象覆盖通信辅助感知、感知辅助通信与网络协同。[1–3]

2023 · 进入 IMT-2030 框架

ITU-R M.2160 将通感一体列为 IMT-2030 的六类使用场景之一。它是愿景和目标框架，不能理解为完整 6G 空口规范已经完成。ITU 官方说明

2024–2026 · 面向标准、信道与可验证系统

3GPP Release 19 的 TS 22.137 描述 ISAC 服务需求；Rel-19 信道建模也有专门综述。服务需求、信道模型、可部署产品是不同层面的成果。TS 22.137 官方文档 · 信道标准化综述 [7]

为什么现在值得研究？

更宽带宽、更大阵列与联网基础设施提供感知条件；车路协同、工业机器人等应用同时需要连接与环境信息。

为什么还没有“顺手就能感知”？

回波可能远弱于直达信号，设备存在收发泄漏与时钟误差，通信数据也并非总是理想的探测波形。理论收益需要工程验证。

03 / 最少的数学

从三个可测量的变化开始

先看单站、单目标、窄带多普勒近似下的回波。发射机与感知接收机共址，忽略杂波与硬件误差：

y(t) = α · x(t − τ) · ej2πfᴅt + n(t)

x(t)：已知发射信号；α：复反射系数；τ：往返延迟；fᴅ：多普勒频移；n(t)：噪声。多目标时对多个回波求和；多天线时加入阵列响应。

DELAY / 延迟

距离 R = cτ / 2

回波到得越晚，目标通常越远。除以 2 是因为信号经历往返路径。

100 m ≈ 0.667 μs
DOPPLER / 频移

径向速度 vᵣ = λfᴅ / 2

目标沿视线方向运动，会改变回波频率。只能直接得到径向分量，符号取决于约定。

λ = c / f꜀
ARRAY / 相位差

角度来自空间采样

不同天线到目标的路径长度不同，形成相位差，可通过波束扫描或阵列估计算法测角。

有效孔径越大，通常越有利于角度分辨。

双站感知中，延迟对应“发射站→目标→接收站”的总路径，不能直接套用单站的 R = cτ/2。分辨率是区分两个目标的能力；精度是单个估计偏离真值的程度。

模型与收发处理背景：信号处理综述 [2]；误差界与指标：性能极限综述 [3]。

04 / 交互小实验

调大带宽，两个目标会发生什么？

假设两个静止目标距离相差 2 m。改变带宽观察理想距离响应；再改变观测时间，比较距离和速度分辨率各由什么决定。

固定载频 28 GHz，c ≈ 3×10⁸ m/s。单站、理想矩形频谱及观测窗；速度变化、同步和信噪比影响暂不建模。

距离分辨率 ΔR1.50 m
速度分辨率 Δv0.268 m/s
目标间距 / ΔR1.33

蓝实线：99 m 目标；绿虚线：101 m 目标。曲线为各自的 sinc² 响应，不是二者相干叠加后的实际测量。

ΔR ≈ c / (2B)　　Δv ≈ λ / (2T)

这是教学尺度估算，不是实际检测成功的保证。加窗会改变主瓣与旁瓣；信噪比、目标强弱差和算法也影响可分辨性。增大带宽可能同时有益于通信与感知，并非所有资源变化都必然造成二者对立。

05 / 读论文前先辨认场景

“谁发、谁收、谁被感知”决定了问题

单站 Monostatic

发射与感知接收共址。已知自身波形，几何关系直接；难点是强自干扰、收发隔离与动态范围。

基站 ⇄ 目标

双站 Bistatic

发射与感知接收分离。空间视角不同；需要处理同步、直达波，以及接收端是否知道发射符号。

站 A → 目标 → 站 B

多站 / 网络化

多节点共享观测与结果。可改善覆盖和几何条件；增加校准、数据关联、回传与融合复杂度。

多视角观测 → 融合

部署与信道背景见 信道建模综述 [4] 与 TS 22.137。

06 / 研究方法地图

先找问题，再选数学工具

看到“RIS + AI + UAV + ISAC”不必被缩写吓住。先判断论文究竟改进了哪个任务、哪个指标，以及它假设知道什么。

研究问题常用方法怎样判断有效读文时要追问
信号与波束怎么发？
波形、预编码、功率分配		约束优化；交替优化；半定松弛 SDR；逐次凸近似 SCA速率–感知误差权衡；功率与复杂度优化是否非凸？只是局部解吗？CSI 是否完美？
回波怎么处理？
检测、距离/速度/角度估计		匹配滤波、2D FFT、CFAR；MUSIC/ESPRIT；最大似然、稀疏恢复固定虚警率下的检测率；RMSE 随 SNR 的曲线多径与目标能否区分？目标数已知吗？
性能上限在哪里？Fisher 信息与 CRB；互信息；容量–失真分析算法距离理论界有多远；可达性能区域界的假设是否成立？低 SNR 或有偏估计时是否仍适用？
真实环境怎么建模？信道测量、几何随机模型、射线追踪；目标 RCS 与杂波建模模型与实测的一致性；跨场景验证通信与感知信道的相关性是否被保留？
多站如何协作？同步校准、数据关联、Kalman 滤波、分布式融合、资源调度覆盖、跟踪误差、时延与回传开销节点时钟和相位真的一致吗？融合的是原始信号还是结果？
复杂环境能否靠学习？监督学习、模型展开、强化学习与模型辅助学习未见场景泛化；对比传统方法；推理成本标签怎么获得？训练/测试是否泄漏？离开仿真还有效吗？

路线依据 [2–5] 及 Intelligent integrated sensing and communication: a survey；表中的检查问题为本站阅读建议。

典型优化题长什么样？

最大化：用户总速率
约束：感知 CRB ≤ 阈值
　　　总发射功率 ≤ P

把 CRB 阈值从严格调到宽松，可以研究性能边界。也可以反过来，在通信最低速率约束下最小化感知误差。

CRB 是满足相应正则条件时无偏估计的方差下界，不等于某个实际算法一定达到的误差。

三种设计入口

通信中心：从现有通信波形出发增加感知功能，例如 OFDM。

雷达中心：保持探测能力，在雷达信号中嵌入数据。

联合设计：显式考虑两套指标，联合选择波形、波束或资源。[2]

07 / 第一项可复现实验

从 OFDM 的距离–多普勒图开始

先做单站、单目标、已知 QPSK 符号的仿真。目标是理解一条完整处理链，不急着叠加 RIS 或深度学习。

① 生成符号子载波 × OFDM 符号网格 X[k,m]
② 加入目标延迟相位、多普勒相位、反射系数与噪声
③ 消去数据逐元素 Y[k,m] / X[k,m]
④ 二维变换沿子载波 IFFT；沿慢时间 FFT
⑤ 找峰并评估距离/速度估计；多次噪声试验计算 RMSE
入门假设：延迟在循环前缀内、多普勒引起的载波间干扰可忽略、同步理想、X 非零且已知。若用幅度变化较大的 QAM，直接相除会放大小幅度符号处的噪声；真实处理还需考虑窗函数、杂波、频偏与泄漏。

建议的起始参数

256 个子载波、120 kHz 子载波间隔、128 个 OFDM 符号、28 GHz 载频；目标距离 50 m、径向速度 10 m/s。选择大于目标往返延迟的循环前缀。

有效带宽约 30.72 MHz，对应理想距离分辨率约 4.88 m；慢时间间隔应包含循环前缀。参数仅用于教学，不代表某一标准配置。

按这三个顺序加难度

  1. 加第二个目标，观察间距与带宽的影响。
  2. 扫 SNR，比较 FFT 峰值估计与更细致估计方法。
  3. 保持总功率、带宽和观测时长可比，研究导频/资源分配对通信与感知的共同影响。

10 / 常见误区与自测

能回答这些，就有了方向感

ISAC、JCAS、JRC、DFRC 是不同学科吗？

它们属于高度重叠的研究谱系。JCAS 强调通信与感知联合；JRC/JCR、DFRC 常突出雷达与通信双功能。具体论文定义可能不同，应先读系统模型，不能只凭缩写划分边界。

“复用通信信号”是否意味着感知完全免费？

不是。可能仍需接收链路、算力、导频、同步、隔离、调度和回传资源。论文中的收益必须连同这些成本一起评估。

带宽翻倍，定位误差一定减半吗？

不一定。理想距离分辨率 c/(2B) 减半，但单目标估计误差还取决于信噪比、模型、估计器和系统误差。精度与分辨率不是同一个指标。

CRB 更低，就说明算法更好吗？

CRB 描述特定模型和条件下的界。设计降低 CRB 说明潜在信息增加，但实际算法可能达不到；应另外报告估计 RMSE、检测性能、复杂度和模型失配影响。

如果喜欢数学 / 编程 / 硬件，应从哪里切入？

偏数学：指标、CRB、波束优化；偏编程：OFDM 收发与参数估计；偏硬件：同步、校准、自干扰与实测信道。三条路线都先建立一个可解释的简单基线，再增加复杂度。
