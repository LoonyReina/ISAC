感知辅助通信 / 一次候选决策

猜中最优波束，
与保住通信增益是一回事吗？

雷达观测已经到手；怎样减少通信端逐个试波束的次数？先让一个训练好的小模型推荐候选，再检查：有没有猜中第一名，少掉了多少功率，又花了几次探测。

原创合成教学模型。没有下载 DeepSense 测量，没有训练论文 CNN，也没有复现论文准确率。这里是感知信息帮助通信选波束；不表示同一射频波形同时完成雷达与通信。

先把“看到了什么”与“想知道什么”分开

通信阵列有 64 个固定指向，编号 0–63。一个方向附近可能有两个波束都很强：选错第一名，不一定损失很多功率。接收机的实际任务，是用有限次探测找一个够好的通信波束。

  1. 拿到感知特征本页合成一个带偏移与噪声的方向读数，以及两项环境特征。真实方向未知。
  2. 用训练样本推荐七近邻模型只读取当前特征，用训练集的波束标签学映射，给 64 个候选排队。
  3. 探测前 K 个，再选最强理想化地测完 K 个候选的通信功率，取其中最高者；这是候选探测后的结果。

先修：阵列相位与方向匹配 · I/Q 与复数功率。暂时不需要懂神经网络；展开后面的模型，才解释七近邻怎么算。

只改一个决定：你愿意试几个波束？

“找例子”是按评估真值挑选的教学样本：只在预测完成后，挑选一个 K=1 的低损失错标签样本，帮助读图；不会改变训练、预测或全体成绩。

① 模型实际读取

这是合成特征，不是雷达原始 IQ、距离–角度图或真实测量。

② 先固定候选排名

排名不随 K 改变。扩大 K 只是取同一队列更长的前缀；分数不是校准后的概率。

③ 现在揭示真值，只作教学评估

下面 64 个功率是模拟器知道的答案。真实接收机在探测前看不到它们，预测器也没有读取它们。横轴是波束编号，不是角度；纵轴是归一化接收功率，线性 0–1，无单位。每根柱是一个波束的功率，不是空间中的目标。

精确标签命中
候选探测后功率损失对比遍历全部 64 个后的最高功率
这次花了多少探测

这里假定每次探测等成本、K 次测量完全准确，而且探测期间信道不变。不计感知采集、推理、训练、波束切换与失败后回退成本。K/64 只是探测次数占比，不能直接换成总时延、吞吐量或能耗收益。

回到种子 37、保留整条轨迹、有校准偏移、K=1 和第 1 条观测

不只看一条：当前 K 在全部保留观测上表现怎样？

同一组 64 条测试观测来自 4 条相关轨迹。先固定所有预测，再揭示标签和功率。下面是这一份合成数据的结果，不是 64 次独立实验，也不是论文成绩。

“波束错标签”与“损失超过 3 dB”是两个不同事件。后者只是本模型选定的功率损失门槛；没有噪声、编码与速率门槛模型，不能称为通信中断率。

最少的模型：方向 → 阵列功率 → 标签

展开阵列、训练和三个指标的计算

把方向用 u=sin(θ) 表示；θ 从阵列法线计，u 无单位。16 个阵元间距为半波长。a(u) 是一个方向的单位范数复数相位向量；拿它与波束 j 的相位向量做匹配，得到该方向的归一化通信功率。

a(u)[m] = exp(jπmu) / √M，m=0,…,M−1，M=16
Pⱼ = |a(u)ᴴa(uⱼ)|²，uⱼ=−0.95+1.9j/63，j=0,…,63
标签 y：在最大功率附近的数值并列项中，取最小编号

这里 j 在 exp(j·) 中是虚数单位，在下标中是波束编号；M 是阵元数。64 个波束在 u 上等距，角度上并不等距。功率只计方向匹配，已把路径增益、发射功率与距离衰减归一化；不是瓦特、SINR 或 bit/s。

训练可用标签，预测不可偷看测试答案。模型保存 512 条训练样本的 x 和标签，把标签换成对应波束坐标 uᵧ。收到新的 x 后，按三维特征的欧氏距离找到 7 个最近训练点，以 1/(距离平方+10⁻⁶) 加权平均它们的 uᵧ，得到 û。再用 û 的理想阵列响应对 64 个波束排序。测试标签、测试真实方向、测试功率、场景/轨迹/帧编号都不进入这个接口。

Sₖ = 固定预测排名的前 K 个波束
命中 = 1[y 属于 Sₖ]
损失 = 10 log₁₀(maxⱼPⱼ / maxⱼ∈SₖPⱼ) dB
探测次数占比 = K/64

损失的分母是把 K 个候选都探测后的最高功率。K>1 时，它不是“直接使用排名第一名”的增益。标签没猜中时，两个邻近波束也可能几乎一样强；K=64 则必命中、损失为零，但没有节省探测。

数值并列采用固定规则：在当前剩余最大线性功率的 10⁻¹² 绝对容差内，先取最小编号，再重复。损失参考实际最大功率，不用并列标签功率替代；指标不设 dB 下限。候选功率恰为零时显示 +∞ dB；浮点 sinc 在解析零点可能留下极小正残差，对应很大但有限的计算损失。本图直接显示线性功率，没有用于指标的显示裁剪。

研究延伸：保留“新帧”，还是保留“新场景”？

展开训练范围、种子与对照条件

先锁住同一批测试锚点：场景 2 的轨迹 8–11，各取帧号除以 4 余 2 的 16 帧，共 64 条。三个方案都训练 512 条，7 个邻居等超参数事先固定。这里可以反复改变条件并查看结果，因此是固定玩具评估集的交互探索，不是未被查看过的最终测试基准。变化的是哪些训练样本允许进入池子。

感知特征是 x=(u+b场景+b轨迹+ε，w·c场景，w·c轨迹)。场景特征固定取 −1、0、1；轨迹特征是每条轨迹固定的随机数。它们人为携带组别线索，不是从真实雷达提取的特征。元数据不进入预测，并不等于特征里没有组别信息。噪声满足 εₜ=0.8εₜ₋₁+0.6σzₜ，σ=0.006，体现时间相关。

默认场景偏移为 0.12c场景；每条轨迹偏移独立均匀取自 [−0.04,0.04]；w=0.18。“去掉偏移”仍保留后两维；“也去掉环境特征”才把它们置零。改变这些设定是一个合成反例实验，不是对真实 DeepSense 数据泄漏或因果机制的判断。

同一 K、同一 64 条测试锚点、各 512 条训练数据；不保证成绩排序
训练范围标签命中平均损失损失 >3 dB同轨迹重叠 / 4±2 帧内有训练邻居的锚点 / 64

交错帧适合问“已经见过同一经过过程，能否对其中未用于训练的帧做插值判断？”训练池可能含有比测试帧更晚的帧，这不是在线下一帧预测。保留轨迹与保留场景则逐步排除这种熟悉程度。随机帧划分不自动等于错误；把同轨迹结果说成跨场景能力，才超出了证据。换种子或移除环境特征，三个方案的次序可能反转。

网页使用独立的 Mulberry32 / Box–Muller 随机数与固定抽样规则；种子相同会复现本页结果，但不与早期 NumPy 原型逐种子一致，也不对应论文的数据划分。这里只有 4 条相关测试轨迹，不绘制把 64 帧当独立样本的二项置信区间。

少试几个候选，还不是完整通信收益

  • 本页的标签、单径 ULA 功率与特征都是原创合成；没有测量天线方向图、多径、遮挡、移动时延、反馈错误或真实雷达特征
  • 预测器确实用训练标签拟合七近邻映射，但它不是论文 CNN；排名分数不代表可靠概率，当前帧决策也不等于预测未来最佳波束
  • 每个 K 的比较保持同一信道、相同 64 波束码本、16 阵元与同一排名。K 增大保证的是候选集合性质；实际速率、功耗与时延可能因额外探测而变差
  • 例如 K=5 的理想次数节省是 1−5/64=92.1875%。这不是实测“93% 端到端节省”；雷达与模型也有成本
  • 超参数事先固定；若开始根据结果挑邻居数或特征，应另划验证集、保护最终测试集，再按轨迹或场景重采样评价不确定性
